Whomi 使用指南

如何导出聊天记录？

找到聊天所在的平台，按步骤导出文件，再拖到 Whomi 桌面端。

选择聊天来源

01微信SIWX 导出
  1. 在存有微信 4.x 聊天记录的电脑上启动微信导出工具 SIWX（Stories in WeChat）。首次使用时，在它的本机控制台选择自己的微信账号，按引导完成解密。
  2. 在「聊天查看」找到想保存的好友或群，核对能看到原文。进入「导出」，勾选这段会话和消息内容，格式选 JSON（结构化数据文件），开始导出。
  3. 打开导出目录。若得到压缩包，先解压。找到对应会话的 .json 聊天文件，把它拖进 Whomi 的「选择文件」区域。若同目录有 manifest.json，那是导出清单，请选择会话文件。

获取和设置 SIWX

02QQ聊天导出工具
  1. 在 Windows 上启动第三方工具 QQ Chat Exporter，按提示登录自己的 QQ。在工具打开的本机网页里点「会话」。
  2. 找到想导入的好友或群，在对应行点「导出」。设好日期范围，格式选 JSON（结构化数据文件），再点「创建任务」。
  3. 在「任务」里找到这次导出，完成后下载文件。如果拿到压缩包，先解压，再把这段会话的 .json 文件拖进 Whomi。

手上已有旧版 QQ 消息管理器导出的聊天文本？可以直接在 Whomi 选择那份 .txt 文件。

获取和设置 QQ Chat Exporter

03Telegram桌面端
  1. 在电脑上打开 Telegram Desktop，进入想在 Whomi 里重读的那段聊天。点会话右上角的「⋮」，选择 Export chat history（导出聊天记录）。
  2. 在导出窗口把保存格式设为 Machine-readable JSON（机器可读的数据文件）。选好保存位置后开始导出。
  3. 导出完成后打开保存目录，把后缀为 .json 的聊天文件拖到 Whomi 的「选择文件」区域。如果目录里只有网页文件，请重新导出并选择 JSON。
04WhatsApp手机端
  1. 打开想保存的好友或群聊。安卓手机点右上角「⋮」→「更多」→「导出聊天」。iPhone 点顶部的联系人或群名称，再点「导出聊天」。
  2. 如果手机询问是否附加媒体，选择「不附加媒体」。用系统分享菜单把导出文件保存到自己能取回的位置，再传到装有 Whomi 的电脑。
  3. 在电脑上查看文件后缀：收到 .zip 就先解压，收到 .txt 就直接使用。在 Whomi 点「选择文件」，打开这份聊天文本。
05Discord频道记录
  1. 打开第三方工具 DiscordChatExporter，按工具提示连接自己的账号，在频道列表中选中想保存的聊天。
  2. 打开导出选项，将文件格式设为 JSON（结构化数据文件），选择保存位置并导出。
  3. 在 Whomi 点「选择文件」，打开刚保存的频道 .json 文件。

获取和设置 DiscordChatExporter

06Google ChatGoogle Takeout
  1. 用聊天所在的 Google 账号打开 Google Takeout（数据导出工具）。取消预选的产品，只勾选 Google Chat，创建一次导出。
  2. 下载压缩包并完整解压，保留 Takeout/Google Chat 下的 Groups 和 Users 两个目录。
  3. 在 Whomi 点「选择文件夹」，选中解压后的 Google Chat 文件夹。如果发现多段会话，勾选想导入的会话。

打开 Google Takeout

07Instagram账户中心
  1. 进入账户中心，在「你的信息和权限」中创建一次信息导出。选择存有私信的 Instagram 账号，导出到设备。
  2. 将信息范围设为消息或私信，选择需要的日期，格式选 JSON（结构化数据文件）。文件准备好后下载并解压。
  3. 在解压目录中找到目标聊天的消息文件，例如 message_1.json。在 Whomi 点「选择文件」选中它；同一聊天有多个消息文件时可多选。
08LINE聊天文本
  1. 在手机上进入一段 LINE 聊天，打开会话菜单，在「设置」中选择「导出聊天记录」。
  2. 通过手机的分享菜单保存文本文件，再把这份 .txt 传到运行 Whomi 的电脑上。
  3. 将文件拖入 Whomi。如果从电脑版 LINE 导出，可在会话菜单选择「Save chat」（保存聊天），文件只包含当时已加载的消息。

拿到导出文件后，在 Whomi 侧栏点「会话」旁的加号，选择文件或文件夹。聊天记录在本机导入。
