# 吕布虚构会话：创作人物设定

先固定人物，再编写对话。本文件是作者侧的创作约束，不导入 Whomi，不作为模型的隐藏答案。

## 史料与创作边界

参考《三国志》卷七吕布传及《后汉书》吕布传：

- 吕布擅长弓马，信任自身武艺。辕门射戟既有武力展示，也有权衡各方形势、阻止冲突的一面。
- 董卓曾向吕布掷戟；吕布表面谢罪而心有不安。两人的依附关系不能只写成亲密父子。
- 吕布重视功劳、待遇和地位，也会因怀疑别人负己而发怒。
- 高顺劝吕布遇事详思、不要反复；吕布知道他忠直，却不总采纳。这可作为短期判断和临时改意的创作依据。

资料：[《三国志》卷七](https://zh.wikisource.org/zh-hans/三國志/卷07)、[《后汉书》吕布传](https://www.shidianguji.com/book/LS0003/chapter/1j7lpp2128qwn_227)。核查日期：2026-11-02。

这些史料不能证明任何现代人格测量结果。貂蝉采用文学人物身份；史书中的侍婢不能直接认定为貂蝉。下列聊天全部为新写的虚构文本，不是古籍原文，也不是历史事实复原。通讯软件、日期及同时出现的人际关系属于架空测试场景，不对应真实年代。

## 固定的创作人格

吕布相信自己的武艺和现场判断，重视功劳是否被看见；面对眼前机会容易改意，在地位受威胁时敏感强硬。他会照顾亲近的人，却容易把主动替对方办事当作关心。当对方把具体后果说清楚，他有时能收住冲动，让出决定权。

| 特征 | 对话中如何表现 | 保留的反例与限制 |
| --- | --- | --- |
| 信任亲自试过的东西 | 选马要试骑，判断渡口要看水痕，换兵器要试握 | 不能据此把所有主张或沉默都算作某个人格维度 |
| 重视认可、容易受辱 | 功劳被转给别人时追问；受猜疑时急于说明自己 | 不把争功写成每次都合理，也不把愤怒等同外向 |
| 看重眼前机会、安排有弹性 | 临时换训练地点、赴约途中改路线 | 遇到粮车和军令仍可能服从明确时限 |
| 关心亲近的人，但起初替人做主 | 直接说要接人、送东西、找人理论 | 对方说清风险后有时等待，有时仍不耐烦 |
| 在部下面前讲能力与实际得失 | 检查地形、比较粮草、核实功劳 | 讲理不代表情绪稳定，也不代表固定的思考型 |

## 三段关系

- **貂蝉**：亲近、担心失去，容易抢先替她解决问题。例：西门之约里，吕布先要闯进去，听见她明日还得独自面对董卓，才同意等她自己开口。
- **董卓**：依附、求认可，同时戒备。例：吕布要求记下自己的战功，却在董卓明确下令后接受次日守门，不把服从直接解释成喜爱计划。
- **高顺**：信任其能力，却讨厌被管束。例：吕布想临时换训练地点，高顺指出粮车会错过，他才给出交接办法。

## 分析的开放结果

不预设四字母人格类型。迈尔斯–布里格斯性格类型指标（MBTI）的方向与置信情况，以正式版真实生成的证据和结果为准。独立事件可以支持不同方向，也可以完全不支持人格判断。无法判断、关系间差异和生成失败都应原样保留。
