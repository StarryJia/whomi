ChatLab 是聊天记录交换格式，本批使用 0.0.2 版。`platform: telegram` 仅复用项目已有导入容器，不代表人物使用 Telegram。每个文件只有两位成员；三个文件的贾宝玉账号编号相同，对方显示为林黛玉、薛宝钗或袭人。消息正文仅保留对白，发言者逐句读取，不假定双方交替发言；背景、回目、标题与审读信息不写入消息。

生成或检查：

```sh
node docs/fixtures/hongloumeng/build-fixtures.mjs
node docs/fixtures/hongloumeng/build-fixtures.mjs --check
```

[生成脚本](build-fixtures.mjs)直接读取剧本，不维护第二份手抄对白。[清单](manifest.json)记录源文件与各导入文件的 SHA-256 校验值、场景编号、总顺序、虚构时间，以及每条消息对应的源文件行号。`messageIndex` 从 0 开始；源行号从 1 开始。检查模式不改文件，核对完整对白、发言者、数量、排序、稳定消息编号和生成结果一致性。

本批编号为 `hongloumeng-v1`。消息编号由批次、源片段编号、片段内发言序号组成，同一版本重复生成保持一致。导入时选择 `conversations/` 内三个文件，核对会话数和消息数后将本人确认为贾宝玉；再次导入相同文件时，应匹配已有会话且不增加消息。实际应用内的导入与去重验证由本轮验收记录说明，生成检查本身不代表应用验收已完成。
