# Whomi 隐私封面与启动动效 Implementation Plan

> 历史计划：对应已完成的封面与动效阶段，保留原任务和验证记录；不重放实施流程。后续总览与分析功能见[自我理解体验](../../designs/whomi-self-understanding-design.md)，本轮只更新文档。

> 执行方式：在当前会话按任务实现，子代理负责独立动效组件与行为测试。用户已确认 main 及入口、封面、动画范围。本轮不自动提交或推送。

**Goal:** 将个人总览收进 Hello 后，实现约 3.8 秒原图分层搜索开场；放大镜匀速运动，小脸中段完全静止 0.3 秒，前后冲近保持既有曲线，最后两层同时停稳组成 Logo。仅启动或刷新播放，不提供重播与跳过按钮，保留 Escape 结束。

**Architecture:** HomeShell 管理内存中的封面/总览状态，StartupIntro 用 GSAP 时间轴与快速位置更新驱动原图分离的放大镜、小脸两层，不叠加第三张整图。原始品牌文件不变，动画落点取自顶部图片元素，敏感页面状态不持久化。

**Tech Stack:** React、TypeScript、Vite、CSS、GSAP 3.15.0、@gsap/react 2.1.2、Vitest。

**Spec:** [已确认入口与动效约定](../../designs/whomi-private-cover-motion.md)。

## Global Constraints

- 在 main 开发，保留未采用的品牌探索图片。
- 最终品牌由原图逐像素分离的两张透明图片自然组成，不重新描摹；复用 GSAP，不新增统计、分析或密码锁。
- 侧栏移除个人总览入口，其他业务仍不可用。
- 启动和刷新默认封面，返回封面不重播，减少动态效果可直接进入封面。
- 保留原侧栏收展、窄屏焦点与品牌首页行为。

## Review Focus

- 首帧和刷新不闪现总览。
- Escape、动画失败和组件卸载不会留下阻塞层或定时器。
- 桌面及窄屏落点与真实品牌一致。
- Hello 和返回按钮可通过键盘完成，焦点不落入隐藏区域。
- 两层透明图片叠合时不露白边，最终轮廓保持原图比例。
