# 会话验收缺口与紧凑阅读修复计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 修复独立验收发现的五项问题，并完成用户确认的引用跳转、紧凑气泡与阅读区元信息隐藏。

**Architecture:** 复用现有导入快照、消息定位及模型任务控制接口。删除前先结束该会话的模型任务；数据事务先删除全部引用关系再清理消息。阅读布局维持现有品牌与分栏，只收紧消息节奏。

**Tech Stack:** 现有 React、TypeScript、Electron、SQLite、Vitest、Playwright；不新增依赖。

**Spec:** 用户本轮明确授权修复；验收依据为本聊天的五项发现，以及 `docs/designs/whomi-import-window-installer-fixes.md`。引用支持可靠编号跳转，不根据文字猜测目标；不开展设置页面的新业务实现。

## Global Constraints

- 用户确认继续当前 main，保留全部已有改动；已执行 fetch 与 pull，本地领先 origin/main 16、落后 0。
- 不提交、不推送、不创建或评论外部拉取请求或工单；只用隔离虚构数据验证。
- 会话不展示消息类型、附件及附件状态；保留真实正文、姓名、时间与引用摘录，不裁剪原文空格或换行。
- 活动导入和部分保存不能因加号重置而失去恢复入口；已完成的新导入入口恢复文件选择。

## Review Focus

- 后一条消息引用前一条时，删除成功且其他会话不受影响。
- 在确认保存及保存中点击加号，仍能取消、继续和看见真实结果。
- 删除会话能中止运行中及排队的模型任务，其他会话任务不受影响。
- 引用目标不在当前分页、目标不可用、连续点击及消息选择模式均不跳错位置或丢失草稿。
- partial 与 ready 全未知空总览保持简洁；真实部分结果与均衡结果保留。
