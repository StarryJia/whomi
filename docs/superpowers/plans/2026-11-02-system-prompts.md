# 系统提示词实现计划

> 执行方式：使用 superpowers:executing-plans 在当前会话逐项实现，测试先行；保留用户已有改动，不自动提交。

**目标：** 将已确认的 C 修订稿接入真实提示词存储与模型请求。
**架构：** 共享四项提示词目录及默认正文；沿用设置通信和本地数据库。创建记忆任务、对话轮次时保存提示词快照，重试及续跑保持原内容。
**技术：** React、TypeScript、Electron、SQLite、已有 Radix Popover 与设置 Modal。
**设计依据：** 本聊天确认的 C 修订稿；`docs/designs/whomi-system-prompts.md`。

## 约束与场景

- 当前分支 `codex/remove-question-return` 已获授权；2026-11-02 拉取 origin/main，领先 2、落后 0。
- 列表只有名称、说明叹号和编辑；不显示分类、默认状态或重复说明。右侧编辑窗含正文、恢复默认、取消、保存。
- 例如用户先点记忆成稿旁的叹号，看到作用和对应功能「整理成记忆」，再打开编辑器；取消恢复原值，失败保留草稿。
- 例如任务甲暂停后修改取材提示词，任务甲续跑仍用原快照；新任务乙才使用新文本。旧任务没有快照时保留内置版本。
- 保留模型所需的输出结构与依据校验；提示词空白、超限和未知编号拒绝保存。
- 不引入新依赖、不访问真实聊天、不调用付费模型、不发布外部内容。
