# Cherry 对话模块迁入验收记录

日期：2026-11-08。对应[第 003 条](../planning/ideas/003-cherry-chat-alignment.md)及已批准的[方案第 1 版](../designs/whomi-cherry-chat-migration-v1.md)。源码迁入和自动回归已完成，保留手工验收及材料缺口，不把隔离原型结果计入产品通过项。

## 已完成的接入

Whomi 使用固定提交 `263667f7a99dfed736c939708a55deb435164820` 的 Cherry 输入核心、延迟加载编辑器、输入历史、消息列表、消息框架、正文部件、动作注册、历史与生成消息分层及虚拟滚动。80 个上游文件可逐个核对来源，其中本地原样保留 35 个，必要适配 45 个；清单另列 1 个本地新文件。具体宿主接入和删除的能力分支见[来源说明](../../src/vendor/cherry-chat/UPSTREAM.md)。

请求执行、模型与技能、SQLite 数据、原文引用和链接边界仍由 Whomi 提供。回答正文继续使用已有 Cherry MarkdownCore 来源，没有改写模型保存的文本。例如用户引用原聊天的两条消息发送甲问题，后台保存后输入框交接下一条乙草稿；甲停止或失败后重试原轮，乙与待发送引用仍保留，已发送引用仍能定位原文。

未加入附件、语音、历史消息编辑、完成轮重新生成、分支或自动排队。生成期间选择新模型只影响下一次明确发送，当前轮与重试继续使用原快照。当前模型停用或配置改变时，沿用后端原有拒绝规则。

## 包体、维护与回退

干净基线网页构建主脚本 1348.91 千字节，压缩后 424.41 千字节；样式 132.12 千字节，压缩后 24.16 千字节。为避免写入原研究目录，在当前隔离工作区中解出 `b637889` 后构建，结果见 `artifacts/baseline-web-build.log`。

最终网页主脚本为 1478.59 千字节，压缩后 468.20 千字节；按需加载的编辑器为 320.16 千字节，压缩后 98.74 千字节；样式为 172.27 千字节，压缩后 31.96 千字节。迁入增加了包体，保留已有的大块脚本提示，未通过抬高警告阈值隐藏它。正式桌面入口 `index-Cy7Pe1st.js`，网页入口 `index-NH0QhYy8.js`。

两版各三次的启动、打开对话和输入 50 字符观测见[运行报告](cherry-chat-runtime-validation.md)。性能样本使用补充菜单交接修复前的 `index-CuLMu8pG.js`，与最终 A15 的产物分别标识。隐藏窗口中，迁入版末轮正文可见约 4.3 秒，基线约 1.9–2.3 秒；不将它概括为性能改善，也不据此估计日常可见窗口响应。同条件滚动耗时与锚点对照因探针不能可靠确认真实滚轮而未完成；真实桌面阅读和长会话静置仍有独立功能证据。

尺寸观察器问题定位到固定版本 virtua 在测量回调中的同步更新。补丁只延后这处回调，不过滤错误、不替换全局观察器。安装时检查原包版本、两个入口的原始和补丁后文件摘要，再应用补丁，重复运行可复核。来源、MIT 许可证和精确摘要见[补丁说明](../../src/vendor/virtua-resize/UPSTREAM.md)。

Cherry 应用代码按实际 AGPL-3.0 来源记录，共用界面包按 MIT 单列；本轮补齐许可证、三份文件清单与桌面打包资源。没有改变项目整体许可，没有发布安装包或推送远端。

隔离副本的界面回退已验证：最终迁入版保存一轮完成回答和一轮停止回答，关闭后复制合成数据库；基线 `b637889` 读取副本，两轮编号、状态、正文、模型身份及引用一致，停止轮引用仍能高亮原消息。未增加模型请求，原合成库的文件摘要保持不变。[回退原始记录](assets/cherry-chat-migration/interface-rollback.json) · [验证方法](cherry-chat-runtime-validation.md)。这项结果不代替未执行的安装包跨版本升级检查。

## 保留的验收事项

1. 在可实际聚焦的 Windows 桌面使用中文输入法，回车确认候选字，再显式发送；应只产生一次请求，保留操作记录。
2. 运行固定提交的完整 Cherry 应用，以相同示例内容核对输入、菜单、消息排版和阅读行为。来源校验和原型截图不替代此项。
3. 取得用户截图对应的原始回答文本后，在两边复测异常 `**`。当前只能说明它通常是 Markdown 加粗分隔符，不能从截图断定具体解析原因。
4. 同条件滚动性能对照未完成；已有加载和输入观测仅为指定产物的隐藏窗口小样本，不作为可见窗口性能承诺。安装包升级两项仍缺所需材料。
