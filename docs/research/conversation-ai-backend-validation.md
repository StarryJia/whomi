# 会话 AI 后端实现与验证

日期：2026-10-30。用户已授权按[后端方案](../superpowers/specs/2026-10-30-conversation-ai-backend-design.md)实施；基线 `36f8136`，继续当前 `main`，保留原有 12 个本地提交。开始前工作区干净，已执行 fetch、pull 并确认落后远端 0 个提交。

## 已接入范围

采用完整 `@earendil-works/pi-coding-agent@1.4.0` 软件开发工具包，在独立 Electron Agent 进程运行；SQLite 继续仅由既有数据进程写入。主进程负责窗口校验、凭据加密、任务调度与进程生命周期。没有自行编写替代 Agent 循环。

| 场景 | 当前行为与可观察结果 |
|---|---|
| 用户分析当前记录 | 打开浮窗只读取本人、模型和固定消息快照；确认后创建任务。分析期间新导入消息留待下一次，重复确认返回同一任务 |
| 保存任务画像结果 | 固定指令分批生成观察、依据编号和限制，再分层汇总；批次原文覆盖去重，最终报告事务提交后才完成。重复分析生成新任务，失败不会覆盖旧报告 |
| 直接与 AI 沟通 | 每段导入会话对应独立线程，后台加载当前有效的该会话分析结果；没有画像仍可普通交流，不声称已经了解用户 |
| 引用与技能 | 页面只提交消息编号和已登记技能标识，后台重读真实原文及技能固定版本；跨会话编号拒绝。分析不加载用户技能；技能不能取得文件、命令或其他原文工具权限 |
| 停止、重试及重启 | 显式停止保留部分文字；重试同一轮次增加执行尝试，不重复提问。关闭侧窗或离页仅解除观察。应用退出取消请求，遗留活动任务标中断，重启不会自行再次调用模型 |
| 长对话与长分析 | 完整界面历史保存在数据库；输入预算不足时，只带近期完整问答重建受控 Pi 上下文，旧记录不删除。当前问题或引用自身超量会提示减少引用。长分析分层合并报告，保存中间节点，继续不重复已提交原文覆盖 |
| 用量与速度 | 每个模型请求独立登记，累计更新替换同一请求；重试消耗累计，消息覆盖不重复。输入、输出、缓存命中与写入按实际回执保存，未知不补零，部分统计标注不完整；速度为客户端活动请求口径，不表示服务商账单 |

例如，合成测试中一条原文分析调用一次批次处理和一次最终汇总，每次回执输入 20、输出 10 token，任务累计输入 40、输出 20；同一条原文的已分析数量仍为 1。token 是模型计量文本的单位。

## 运行与配置

使用 `npm run desktop:dev` 运行桌面应用；单独网页 `npm run dev` 没有 Electron 桥接，开发预览继续使用显著标注的模拟适配器。

模型设置页面尚未开发。本轮提供正式后台登记、替换密钥、读取配置及连接检测接口。开发调试可在桌面页面的开发者控制台调用：

```js
await window.whomi.ai.saveModel({
  id: 'local-example',
  label: '本机示例服务',
  model: '填写服务中实际存在的模型标识',
  baseUrl: 'http://127.0.0.1:11434/v1',
  contextWindow: 8192,
  maxTokens: 1024,
  enabled: true,
  apiKey: '',
})
```

上述地址和模型仅是配置示例，不表示已安装该服务。`contextWindow` 和 `maxTokens` 分别是模型上下文容量与本次最大输出量，按服务实际能力填写。远程服务在同一接口填写实际地址和密钥。新登记模型后重启桌面应用刷新当前模型列表；连接检测 `window.whomi.ai.testModel('local-example')` 会发送一条短请求，应在确认目标服务后主动执行。密钥不回传，未提供 `apiKey` 保留原密钥，空串清除；系统加密不可用时拒绝保存非空密钥。

准备、确认、查询与停止分析，以及打开线程、提交、重试、停止轮次的正式接口见 [ai-contract.ts](../../src/shared/ai-contract.ts)。查询报告使用具体任务编号 `getReport(taskId)`。后台还提供继续已提交批次后的接口，身份、模型或提示词版本变化时拒绝混合续算；当前页面的重新分析仍先确认并建立新任务。

用户的提示词、相关画像和明确提供的原文会交给所配置的模型服务。服务地址不能可靠判断推理发生在本机还是远端；数据处理说明将由模型设置页统一承载，不在每次分析重复弹窗。

技能后台只消费已登记的版本化正文。安装、卸载、资源文件授权与管理页面仍未实现；没有偷偷加载用户其他 Agent 的技能目录。报告管理页尚未实现，查看分析结果入口保持未开放，后台已经能按任务读取报告。

## 关键隔离与恢复约定

- 使用 Pi 官方自定义 `ResourceLoader` 提供固定资源，不调用默认包管理器，不扫描宿主技能或扩展；关闭自动压缩、自动重试及缓存预热，不产生未归属的额外模型请求。
- 默认工具与自定义工具均为空；后台没有任意文件读取、命令执行或自动向联系人发消息的能力。登记技能正文进入本轮受控系统指令，不能扩大资料范围。
- Pi 原生历史位于本应用用户数据目录 `ai-runtime/sessions`。恢复时验证真实路径属于当前线程目录，重新打开后切回已提交节点；中断尝试的节点不会直接成为下一轮上下文。
- 数据库升级至版本 4。模型配置及密文按版本保存，任务绑定身份指纹、模型版本、提示词版本和消息快照。身份变化使旧报告失去当前有效资格，后续对话不复用旧身份历史。
- 画像只是任务内观察与限制，不包含未经验证的人格计分算法；不自动聚合到个人总览，不自动触发 Spark 或问一问。

## 验证证据

新增行为按先失败、再最小实现的方式验证：协议和窗口归属、系统加密失败、确认去重、跨会话引用、固定快照、覆盖与用量去重、报告提交失败、身份变化、恢复、提示词版本变化、长上下文、分层汇总及停止重试竞态。存储测试使用真实临时 SQLite，Pi 测试使用真正的软件开发工具包与本地可控 HTTP 服务。

本轮最终验证：

| 命令 | 实际结果 |
|---|---|
| `npm test -- --reporter=dot` | 20 文件、175 项通过 |
| `npm run test:backend -- --reporter=dot` | 标准命令最终 21 文件、288 项通过；其中 Pi 真实本地 HTTP 测试 11 项 |
| `npm run typecheck` | 前端与 Electron 类型检查通过 |
| `npm run build` | 网页生产构建通过 |
| `npm run desktop:build` | 主进程、数据进程、Agent 进程、预加载和桌面页面构建通过 |
| `npm run test:desktop` | 9 项通过，包含新增真实 AI 界面链路及原有导入、分页、隔离和崩溃恢复 |

最终高并行后端运行曾出现 5 项既有导入用例超出 5 秒，随后清理遇到忙碌文件；同一代码与全部断言在两个工作进程下 288 项通过。后端配置固定两个工作进程，不删除或跳过测试。后续标准复跑时 Pi 首项冷导入超出 20 秒，单独重跑 11 项在约 3 秒内通过；现将依赖初始化放入独立准备步骤，保留业务行为的原有 20 秒上限，真实冷进程仍由桌面用例覆盖。新桌面用例最初在测试页面重载步骤遇到导航中止，改用真实重启读取配置后通过，没有放宽产品导航保护。用量完整性字段引入的类型错误也已修正并重新通过类型检查及两种构建。

真实桌面用例覆盖：配置密钥经系统加密保存且页面不可读回；确认前零模型请求；真实 Pi Agent 进程完成分析并保存报告；真实会话界面选择原文、发送并显示回答；重启后线程与报告仍可读取。测试资料、服务和密钥均为合成示例，没有读取私人消息或调用付费模型。

本轮没有验证真实服务的推理质量、所有服务商协议、用户技能安装机制、报告管理界面、全局画像聚合或安装包公开分发。开发预览中的虚构回复仍不是模型效果证明。模型上下文预算采用保守字节上界，极端超长单条结果或不能缩短的汇总会明确失败，不承诺任意规模无限分析。
