## 一条已实际读到的记录

第 0 段含 11 条文本发言，以及提交、接受交易两个事件。第一位参与者先提出共同商议，再与对方协商木柴等物资分配，中途澄清误解，最后提出双方的具体份额。该角色的问卷字段如下，数据来自原文件。

| 大五维度 | 分数，量程 1–7 |
| --- | --- |
| 外向性 | 5.0 |
| 宜人性 | 6.0 |
| 尽责性 | 6.0 |
| 情绪稳定性 | 5.0 |
| 开放性 | 5.5 |

对应路径是该段 `participant_info → mturk_agent_1 → personality → big-five`。聊天条目的 `id` 为 `mturk_agent_1` 时，就能关联到这份分数。导入 Whomi 时只选原始聊天和有必要的任务背景，问卷分数、私下准备的理由、评阅标签留给评阅者。原始文件还含人口统计信息，当前证据与解释评测无需使用这些字段。

原数据中的 `mturk_agent_1`、`mturk_agent_2` 是每段内部的角色名，会重复出现。2,060 份角色记录不能解释为 2,060 名独立参与者。本轮未发现可跨对话关联同一真人的稳定匿名编号，因此也不能把不同对话直接当作独立的人进行统计，或声称已按真人划分训练与测试。人格字段提供五维汇总分，未包含十个问题各自的作答，当前文件无法用来独立重算原始问卷得分。

## 实验真实性的公开证据

CaSiNo 正式发表于 2021 年北美计算语言学协会会议。论文报告从美国 Amazon Mechanical Turk 众包平台招募 846 名参与者，设任务通过记录门槛并支付基础报酬及谈判奖励。正文第 8.1 节报告机构伦理审查、知情同意、可退出和匿名化，附录说明清理不完整及低质量材料。原文未提供伦理审批编号或招募、付款的原始审计记录。[正式论文及数据采集说明](https://aclanthology.org/2021.naacl-main.254.pdf)

后续的 NegotiationToM 研究由另一作者团队将 CaSiNo 的部分对话再次标注意图等内容，报告了 395 段来源对话。这提供了公开数据被实际复用的证据。原 CaSiNo 仓库中有 396 段策略标注，两项数字对应各自发布的材料范围。[后续研究及方法](https://aclanthology.org/2024.findings-emnlp.244/) · [后续研究数据仓库](https://github.com/HKUST-KnowComp/NegotiationToM)

据此可以把 CaSiNo 作为有公开来源与复用记录的真人实验语料。论文对实验实施的报告、本次取得的公开文件、后续团队的再利用共同构成可追查的证据链。公开材料尚不足以独立审计每位被试及每次作答。

## 人格数据怎样用

人格分数来自谈判前填写的十项人格量表，即 Ten-Item Personality Inventory（TIPI），属于自评结果。该量表每个维度仅两项，开发者将其定位于时间有限时使用的简短测量。量表的测量精度限制要随评测结果一同保留。[量表开发者说明与评分规则](https://gosling.psy.utexas.edu/scales-weve-developed/ten-item-personality-measure-tipi/)

物资优先级由实验随机分配。第 0 段第一位参与者优先争取木柴，是在完成这个任务，不能据此替换其人格分数。CaSiNo 的人格字段为大五体系，转换到 MBTI 的适用范围见[对应关系与评测用法](issue-49-personalityevd-review.md#大五人格与-mbti-怎样对应)。

建议优先利用完整英文对话及独立自评数据设计评阅，已有六轮中文意译只作阅读示例。中文版本需额外核对翻译对语气、缓和表达与指代的影响。原文件采用研究者的数据结构，转换为 Whomi 的聊天导入格式尚待实施，当前没有执行新的模型实验。
