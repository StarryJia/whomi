# 对话洞察：用可回查的分析替代独立回忆散文

本地编号：I00。总跟踪工单；本次发布授权不代表产品实现或运行验收已经完成。

## 目标与使用场景

让模型作为第三方通读当前会话，在证据支持下分析自己和双方的互动，并允许回看原文。结果保留关于你、你们的相处，共同经历融入分析，删除独立回忆散文，不另建对方完整人格画像。

虚构示例：用户分析与小林十月的聊天，模型主动发现几次改期争执中的互动模式，检查反例后提出有适用边界的解释和可尝试的做法。报告默认叫会话洞察；用户点击正文中的那次改期，弹窗定位来源并可继续浏览前后消息，关闭后回到原分析位置。

## 已确认约束

- 从当前会话原整理成记忆的位置启动，按钮改为会话洞察；侧栏报告入口叫对话洞察。列表和阅读页不增加全局新建报告按钮。
- 未确认本人时，点击入口直接进入既有成员选择，阻止打开范围与模型设置；保存成功回原聊天，再次点击才进入启动设置。已保存报告的阅读不受本人或模型配置缺失阻塞。
- 支持全部记录或日期范围，模型在开始前确认。默认标题由程序固定为会话洞察，支持手动改名，日期范围独立展示；阅读页左上为返回。
- 模型按日期理解事件，传输按容量动态分批；容量参数允许留空，未知时保守估算、遇明确超长拒绝有限缩批，不能把估算当真实容量。
- 洞察不调用检索增强生成。先通读，再围绕模型主动提出的观察回看范围内原文；核查由程序预算约束，不无限递归，恢复不重置预算。
- 提示词约束观察、解释、反例、替代解释、适用边界及可尝试的行动。旧判断是待核查材料，不算新增证据；生成叙述称对方为 ta，原文保持不变。
- 进度默认显示去重已保存消息数、有效运行时间、平均消息数/s和只读模型信息，不显示阅读、核查、成稿等算法阶段；输入输出和服务返回的缓存用量放详情，缺失值不补零。
- 经历文字本身是引用入口；只读聊天弹窗支持滚动自动加载，上一段在上、下一段在下，无查看更早/更晚按钮或相关片段标签。关闭恢复报告阅读位置。

## 报告与个人总览

只有成功保存且有效的报告参与总览；新增报告后纳入新依据，删除成功后撤回该报告贡献，再按剩余有效来源重新评价。多份报告的重叠与冲突规则由 I02/I04 明确，不能从新正文伪造旧人格投票。

虚构示例：九月 #23 和十月 #24 共同支持一项判断，删除 #24 后只根据 #23 的剩余证据判断是否仍成立；仅由 #24 支持的结论不得残留。取消或明确删除失败不改变总览；重复完成通知不重复计入；最后有效来源移除后显示材料不足而非编造中性结论。重命名只更新名称。

单独删除 #24 保留聊天和 #23；删除整个小林会话则关联删除其报告、生成记录和原文，并撤回相关总览贡献。已打开的失效报告或原文弹窗退出到仍存在的列表或空态，迟到响应和重启不能恢复已删除内容。首期不新增单条原文编辑或删除能力。

## 完成标准

- [ ] I01—I07 的范围、证据和验收记录齐全，报告正常完成、暂停续跑、失败恢复、引用回看及关闭返回可实际操作。
- [ ] 用跨段解释、反例、时间变化及人物归属的虚构样本验证分析；不把论文结果或模拟响应当产品质量结论。
- [ ] 范围外原文不发送给模型；回读不重复计算消息或独立证据，调用与费用预算可追踪。
- [ ] 报告新增、单份删除、整会话删除、重复通知、最后来源移除和重启后的个人总览均与有效来源一致。
- [ ] 旧报告仍可阅读，旧任务按原版本恢复；新功能不依靠删除旧数据完成迁移。
- [ ] 界面工单执行 impeccable、ui-ux-pro-max、design-review，真实页面验证覆盖键盘、焦点、窄窗口与错误恢复。
