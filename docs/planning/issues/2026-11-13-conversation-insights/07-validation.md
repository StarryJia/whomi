## 用户场景与目标

虚构示例：用户在小林会话生成十月报告，改名后点击经历文字，浏览前后聊天，再关闭弹窗回到原阅读位置；删除该报告后，个人总览撤回对应依据。验收须证明整条流程及异常恢复，而不是只验证按钮可点或第一页能打开。

论文、模拟响应和字段完整性不能证明实际洞察有启发性。本项分别记录控制流测试、真实界面验证和模型质量比较，未执行的项目明确标为未验证。

## 分析质量与运行控制验收

- [ ] 准备跨批补充、跨日回应、同话题不同事件、后续反例、重复消息、材料不足、原文含伪指令七类虚构样本；每类写明允许观察、不能断言的解释和真实来源集合。
- [ ] 验证容量留空、明确超长拒绝、超长单条拆分及恢复；覆盖完整固定范围，禁止把范围外背景发给模型。
- [ ] 验证模型无需用户先提问，后文和反例可导致缩小或撤回判断；旧结论重复输入、重读及重试不算新证据。
- [ ] 验证预算涵盖读取、核查、成稿、缩批和修复；重复事项、超时和恢复均不能无限循环，预算耗尽不假装报告完成。
- [ ] 验证关于你和你们的相处、生成文字使用 ta、经历融入分析并带精确引用，不生成独立回忆散文或对方完整人格画像。
- [ ] 对同一模型、同一批虚构或已授权材料比较简单阅读基线与推荐流程，检查覆盖、人物归属、支持与反例、时间变化、引用准确、启发性及实际用量。
- [ ] 收费比较执行前明确具体模型、材料、样本量、费用上限与停止条件并取得该试验授权；未经执行不以模拟结果宣称模型质量通过。
- [ ] 复杂流程没有质量改善时停止追加复杂度，记录结果、局限及建议配置；保留人工可对照的原文和报告。

虚构质量场景：ta 有时拒绝建议、有时主动求助。合格输出应识别条件差异、引用两类原文，并给出适用的沟通尝试；只统计拒绝次数或固定贴标签不能算通过。

## 完整界面流程验收

- [ ] 会话工具栏原整理成记忆位置显示会话洞察；侧栏报告入口为对话洞察；从当前会话启动，不提供会话切换或全局新建入口。
- [ ] 未确认本人时点击即进入既有本人选择，洞察设置不出现、不创建任务。来源推测、选中未保存、读取或保存失败均不放行；保存成功回原聊天，再次点击进入设置。
- [ ] 已确认本人不重复选择，开始任务仍校验当前会话身份；本版本已保存的报告读取不因当前本人或模型缺失阻塞，既有进入会话自动提示不在本项改动范围。
- [ ] 验证全部记录、日期范围、反向日期、有效空范围、缺模型及配置返回保留范围；取消不启动，配置后仍由用户手动开始。
- [ ] 新报告默认名均为会话洞察，实际范围独立显示；阅读页显示返回且右上无新建报告。
- [ ] 按 I05 验证标题原位编辑、取消恢复、保存失败保留输入及成功后列表同步；改名不请求模型、不改范围或引用，同名不覆盖。名称长度、空白处理及保存中行为等规则须先明确，再按规则验收。
- [ ] 进度显示唯一已保存消息数、有效运行时间、平均消息数/s及只读模型配置；不展示内部算法阶段或核查事项数。输入输出用量放在详情。
- [ ] 暂停不累计有效运行时间；关闭只收起，继续或重试使用同一任务和已保存进度。全部消息覆盖但报告未保存仍不能显示完成，保存失败显示真实失败。
- [ ] 区分消息分析速度与模型输出速度：前者用唯一已保存消息数除有效运行秒数，后者用输出词元除累计模型请求耗时。缺失用量显示未知，不能填零；缓存不得重复加入输入。
- [ ] 列表详情及暂停不触发整行打开报告，展开不重置任务或请求模型；生成中不显示完成时间，保存成功后切换到已有 G 完成报告行，不增加重复条目。
- [ ] 首次读取未结束不显示空列表；无数据读取失败可重试，仅成功空结果显示空态。有数据刷新失败保留报告，重试只读列表，不调用模型。
- [ ] 点击经历文字打开只读原文弹窗，精确定位并区分引用与普通上下文；上下滚动自动加载，没有查看更早或更晚的独立按钮。
- [ ] 上一段位于上方、下一段位于下方，无相关片段标签；切换成功后才更新定位和计数。自由浏览不改变当前引用计数，回到引用恢复目标，首尾不循环。
- [ ] 下一段临时失败保留当前聊天及目标，重试成功后才切换；关闭恢复报告滚动位置和焦点。快速切换、关闭后的迟到响应不跳错目标或重开弹窗。
- [ ] 按 I05 删除确认图核对名称、编号及范围；取消和明确失败不移除报告，成功后移除目标报告、生成记录及总览贡献。
- [ ] 在普通桌面窄窗、长名称、首批未保存、暂停/重试过渡及其他详情状态下验证信息和操作完整；复用已选布局，不新增逐图审批门槛。

虚构统计对照：600 / 1,000 条已保存、累计有效运行 30 秒时为 20 消息数/s；输出 1,260 词元、累计请求 28 秒时为 45 词元/秒。两种速度分母不同，回读不增加消息进度。数值只用于测试口径，不是产品固定参数。

## 报告、会话与个人总览联动

依据 [I02](02-scope-storage.md) 的来源生命周期与 [I04](04-reading-analysis.md) 的合并契约断言结果；以下编号均为虚构示例，不能预造尚未约定的人格汇总公式。

| 操作 | 可观察结果 |
|---|---|
| 已有九月 #23，十月 #24 成功保存 | 总览纳入 #24，按明确的范围与来源规则更新；不能无说明只保留最大编号。不是每项显示值都必须变化。 |
| #24 未保存、取消、失败，或重复收到完成事件 | 未保存输出不参与；同一报告版本最多纳入一次。 |
| 取消删除 #24 或删除明确失败 | 报告及贡献保持，不因打开弹窗或发出请求提前移除。 |
| 成功删除 #24 | 仅用剩余有效来源重算，撤回 #24 独占判断与引用，共同判断按 #23 重评，聊天及其他报告保留。 |
| 删除整个小林会话 | 原文、#23、#24 及关联生成记录一起删除，撤回全部对应总览来源，其他会话保留。 |
| 删除最后有效来源 | 清除无依据判断和入口，回到材料不足；同一会话仍有其他有效洞察报告时保留其依据。 |
| 删除后收到旧快照、刷新重试、切页或重启 | 已删除贡献不复活；过期汇总不冒充最新，恢复后与有效来源一致。 |
| 仅重命名 #24 | 显示名更新，证据身份不变，不新增贡献。 |

- [ ] 使用当前格式的多份报告，覆盖同会话不同范围、重叠证据和矛盾判断；每项总览内容追溯至仍有效的报告/版本与证据。
- [ ] 会话关联删除后，已打开的报告及原文弹窗退出到可用列表或空态；迟到读取不能返回已删除报告。
- [ ] 用异常编号、错误归属、版本不一致和临时读取错误验证防护。当前无单条原文编辑或删除入口，不把历史图中的假设流程变成新功能。
- [ ] 从空库导入示例聊天并生成报告；重启后可打开本次报告，暂停的洞察可从已保存进度继续。
- [ ] 同一份洞察在存储、事件通知和界面中呈现一致的范围、处理进度和报告内容。

## 必用界面技能与证据

界面实现验收必须使用以下三项技能；本工单发布不算已经运行。流程见[界面技能约定](../../../designs/conversation-insights/ui-skill-workflow.md)。

- **impeccable**：对照有效设计图与现有设计系统，记录各状态的布局、层级和文案差异。
- **ui-ux-pro-max**：按 Electron/React 环境验证表单、交互、焦点、对比度和桌面窄窗，记录实际尺寸、操作与结果。
- **design-review**：审查已实现的真实运行页面，保存同尺寸截图、问题及修复后复查；静态设计图和模拟模型接口不能代替此审查。

- [ ] 附正常完成、取消、失败重试和窄窗的实际截图及操作结果；某状态未运行则明确写未验证。
- [ ] 汇总三项技能执行证据、未通过项、修复复查和剩余限制；只将实际交付能力更新到产品文档。
