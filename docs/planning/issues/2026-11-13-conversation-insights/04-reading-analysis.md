# 对话洞察：实现有证据、可修正且有预算约束的阅读分析

GitHub 工单：[#14](https://github.com/StarryJia/whomi/issues/14)；2026-11-15 已发布。

**2026-11-15 实施回填：** 已实现可恢复阅读、按需核查和成稿，核查保留逐字验证摘录及冻结的日期、作者与回复关系；压缩导航保留全部子节点。新增报告使用结构化依据参与本地总览。真实模型是否提出核查与质量收益单独记录，不以模拟测试代替，见[实施验证](../../../research/conversation-insights-validation.md)；下方为发布时验收要求。

工作编号：I04。以下为待实施需求，不代表功能已经完成。

## 用户场景

虚构示例：前几段聊天中，你急于给建议，ta 反复说想先讲完；后面的聊天却出现 ta 主动请你出主意。模型应回查两类原文，将观察修正为帮助时机与需要可能不匹配，并给出可尝试的沟通方式，而不是直接贴控制欲强等标签。

用户无需先提出问题。启动洞察后，模型主动阅读、提出观察、核对支持与反例，最终输出关于你和你们的相处。共同经历融入分析，不再单独生成回忆散文；涉及双方在这段关系中的表现，不生成 ta 的独立完整人格画像。

## 阅读流程

- [ ] 顺序覆盖 I02/I03 提供的冻结原文，保留事实观察、暂定解释、来源编号、未结束事项及待解指代；日期交给模型理解，不按批次或自然日制造事件。
- [ ] 用带来源的简短笔记承接批次。大规模材料可分层汇总笔记以供导航，但摘要不替代原文成为证据，也不每批重写整个报告。
- [ ] 根据已读材料形成有限的候选判断及核查事项。事项是一条具体待验证的判断或疑点，例如建议是否只在 ta 尚未讲完时造成不适。
- [ ] 让模型输出受校验的回读请求；程序按消息编号或已读时间范围读取原文。洞察不调用未来问答的检索增强生成服务，不构建向量索引或全库语义检索。
- [ ] 对主要判断查找支持、反例及替代解释，必要时缩小适用范围或撤回判断；完成核查后再成稿。
- [ ] 旧判断再次输入时标记为待核查判断，保留证据和适用时间。重复输入不增加证据；区分后来行为改变与后来信息改变对早期行为的解释。
- [ ] 所有读取请求验证归属、固定范围和来源；引用必须落到真实原文。聊天中的伪指令仅作为被分析材料，不能更改任务规则或扩大读取范围。
- [ ] 复用现有文本运行器并验证两条模型调用路径，不把原生工具调用能力作为未经验证的前提。

## 提示词中的分析规范

以下要求进入阅读、核查、成稿提示词及输出校验；结构齐全不能替代人工语义评审。

- [ ] 分开可查证行为与解释。把支持、反例、替代原因和适用边界写入内部记录；允许无结论、材料不足、合作与成长，不强制制造问题。
- [ ] 重要见解说明具体行为、双方如何相互影响、可能的其他解释，以及可尝试的行动；行动与原文有关，不能保证关系改善。
- [ ] 生成文字称对方为 ta，保留关于你和你们的相处两部分；原文引用保持原貌，不改写聊天称谓。
- [ ] 用经历文字绑定精确引用，供 I06 点击定位；报告标题由程序设置，模型不生成候选标题。
- [ ] 不以固定人格标签、临床判断或投票数量代替解释，不从这段关系的表现推断 ta 在所有关系中的人格。

虚构对照：三次争执后均由你先恢复联系是可以核对的行为；你更害怕失去关系是解释，须核查 ta 的修复方式和其他原因。最终可以提出先确认彼此需要倾听还是建议的尝试，并引用 ta 主动请求建议的反例，表明判断的适用边界。

## 有界核查与断点

- [ ] 持久保存覆盖记录、候选判断及修订、核查队列、已读来源、请求结果和预算；暂停、重试、重启不重置预算。
- [ ] 在请求前预留预算，限制候选事项数、每项轮次、总调用数和总输入输出用量。缩批、解析修复、超时、重试、层级汇总及成稿都计入同一任务上限。
- [ ] 为重复的事项和来源请求去重；没有新增证据或判断变化时停止该项核查。模型不能通过更换措辞无限创建等价事项。
- [ ] 材料覆盖、主要判断回查和重要矛盾处理完成后结束核查。轮数和预算值由验证配置决定，最多两轮不作为已确认固定参数。
- [ ] 覆盖或必要核查未完即耗尽预算时，保留断点及未解决事项，不把半成品标为已完成报告；只有最终报告校验并保存成功才能完成。
- [ ] 保留未知用量的真实状态，不能用零代替缺失值规避预算；取消后不继续发起模型请求。

虚构示例：模型连续两次请求同一段原文来支持同一判断，没有新证据时结束这项核查；任务恢复后仍沿用之前消耗，不能重新获得整份预算。

## 个人总览接入

- [ ] 与 [I02](02-scope-storage.md) 先对齐报告稳定编号、内容版本、本人归属、有效状态、判断和证据契约；完成保存后提供可消费的结构化输出。
- [ ] 明确同会话不同日期、重叠证据、新旧格式和冲突判断的合并规则；不默默采用旧流程仅最新报告规则，不把重复分析当独立新证据。
- [ ] 定义来源撤回后的重算规则，允许材料不足与矛盾；不得靠解析展示段落或伪造旧人格投票字段接入。
- [ ] 用模拟输入证明：删除报告后，只使用仍有效的来源重评；新增、删除、重复通知与重命名符合 I02 生命周期契约。

2026-11-15 用户已选择本地聚合，不增加模型调用。报告提供带来源的结构化判断，本地按来源去重、保留冲突、删除后重新计算；完整规则见[总览契约](../../../superpowers/specs/2026-11-12-conversation-insights-design.md#个人总览与报告增删联动)。完成条件仍是契约可验证、来源可追溯、增删结果可恢复，而不是仅增加一次页面刷新。

虚构示例：#23 与 #24 都支持某个沟通观察，#24 单独提供反例。删除 #24 后不能保留该反例，也不能直接删除仍由 #23 支持的全部内容；只用 #23 重评，没有剩余依据则撤回。

## 验收标准

- [ ] 不输入用户问题也能主动形成观察；弱证据允许不作判断，跨段后文可修正前文解释。
- [ ] 原文支持、人物归属、反例与时间变化可人工核验；旧结论重复输入不计为新证据。
- [ ] 每个引用落在固定范围中的真实消息；范围外读取、伪指令和伪造编号被阻止。
- [ ] 重复请求、输出截断、解析修复、超时及容量缩批均有上限；暂停恢复不增加预算或重复计算覆盖。
- [ ] 消息进度只计算首次完整处理且持久保存的唯一消息；全部消息覆盖不等于报告已完成。
- [ ] 两条模型路径在模拟服务下通过结构输出、取消、失败恢复及未知用量场景；无需另一个索引模型。
- [ ] 新提示词有独立键和版本；旧任务保留其原始指令快照与读取兼容。
- [ ] 总览只消费完整保存的有效输出；取消、失败或重复恢复不生成部分、重复或无法撤回的贡献。
