## 用户场景

示例数据均为虚构。用户在小林会话生成十月报告，默认标题为会话洞察，随后手动改为那次合作。十一月补导聊天后，旧报告仍只代表当时选定的十月材料；删除这份报告时保留聊天，个人总览撤回它提供的依据。

当前任务的最大消息编号只能冻结追加边界，旧报告缺少新洞察所需的范围、可编辑标题及精确引用映射。新存储需在保留旧报告、旧任务的同时，为分析、引用和总览提供同一份可信来源记录。

## 范围与待办

- [ ] 扩展分析准备参数，支持当前会话全部记录或起止日期；保存范围采用的时区、实际起止时间及本人归属。
- [ ] 开始时冻结选定消息清单、消息顺序、内容指纹与版本；后续补导不会悄悄扩大已开始任务的分析范围。
- [ ] 保存新报告格式、稳定报告编号、内容版本和独立标题。新报告标题由程序固定设为会话洞察，范围独立保存，不由模型生成标题或自动拼接日期。
- [ ] 提供报告重命名及精确引用读取接口。引用绑定真实消息编号、会话归属、任务范围及版本；片段位置指向原始消息，不能凭生成文本反推原文。
- [ ] 通过现有数据库迁移升级，保留旧报告读取和旧任务续跑所需版本、指令快照及断点；不为缺乏精确来源的旧报告伪造引用。
- [ ] 定义个人总览来源契约：报告编号与版本、本人归属、有效状态、范围、判断及证据引用。与 [I04](04-reading-analysis.md) 对齐可消费的分析输出，禁止解析展示文案或伪造旧人格投票字段接入。
- [ ] 报告完整保存成功后纳入总览来源；删除成功后撤回其贡献，按剩余有效来源重算，并更新或使持久汇总缓存失效。
- [ ] 用稳定编号与版本去重完成、恢复、重试事件；旧响应不能覆盖较新的删除状态，重命名不能制造新来源。
- [ ] 分别实现单报告删除和整会话删除的来源清理，并向界面提供可判断报告失效的结果或事件。

## 两种删除的边界

| 操作与虚构示例 | 预期结果 |
|---|---|
| 删除小林会话十月报告 #24，九月 #23 仍存在 | 删除 #24 及其生成记录、撤回其总览贡献；保留原始聊天、#23 和其他报告。 |
| 删除整个小林会话，原有 #23 与 #24 | 沿用现有事务删除该会话原文、全部报告及关联生成记录，撤回两份报告的总览来源；其他会话保留。 |
| 取消删除或删除明确失败 | 不提前移除报告或贡献；若运行任务已停止，返回真实任务状态，不承诺继续运行。 |
| 界面仍打开已经删除的报告或其原文弹窗 | 通知界面退出到可用列表或既有空态；迟到结果不能重新加入报告、来源或弹窗。 |

当前正常导入为追加和去重，没有单条原文编辑、删除或替换入口；确认本人也不删除原文。本期不新增这些入口，不实施整会话删除后仍返回旧报告的历史图流程。来源编号、内容版本及归属异常仍须校验，临时读取失败保留重试能力。

## 总览契约的完成条件

当前旧实现使用每个会话最新有效的旧记忆报告及事件投票。新洞察不能默默沿用仅按最大报告编号取一份的规则。

- [ ] 写明新旧格式共存时的有效来源集合、范围重叠去重、冲突判断与撤回协议；I02 负责来源存储和生命周期，I04 负责分析输出及合并规则，接口先对齐后实现。
- [ ] 用模拟输入验证不同范围、重叠证据、冲突判断与最后来源删除；总览每项内容能追到实际参与的有效报告和证据。
- [x] 2026-11-15 用户选择本地聚合，不增加模型调用；保留结构化判断及来源，去重重叠依据，保留冲突，删除后以剩余有效报告重算。完整规则见[总览契约](../../../superpowers/specs/2026-11-12-conversation-insights-design.md#个人总览与报告增删联动)。实现与验收仍分别记录。

虚构示例：#23 与 #24 共同支持某项观察，只有 #24 包含一个反例。删除 #24 后，反例及其独占判断撤回，共同观察仅按 #23 的剩余依据重评；不机械删除整项，也不保留已删除证据。结果文字可以不变，但来源必须更新。

## 验收标准

- [ ] 日期结束日整天包含、次日零点排除；无效日期、空范围及范围外消息不能启动或进入分析输入。
- [ ] 全量与日期范围报告初始标题都为会话洞察；改名不改变编号、范围、正文或来源，同名不覆盖另一份报告。
- [ ] 错误会话、范围外编号和不匹配版本被拒绝；测试通过注入异常数据验证，不假设已有原文编辑功能。追加新消息不使未改变的旧引用失效。
- [ ] 空库及旧库迁移通过；旧任务按原版本续跑，旧报告可读且不出现伪造引用。
- [ ] 未完成、取消、失败或尚未保存的输出不加入总览；重复完成和恢复重试不重复贡献。
- [ ] 删除 #24 后，总览无其独占判断或悬空来源；#23 和聊天保留。删除最后有效来源后回到材料不足，不生成无依据的中性人格分数；仍有有效旧来源时不错误清空。
- [ ] 切页、重启、刷新失败后重试都与当前有效来源一致；过期汇总不能冒充最新结果，迟到快照不能复活已删除贡献。
- [ ] 整会话删除与单报告删除分别通过上表场景，重命名仅同步显示名。
