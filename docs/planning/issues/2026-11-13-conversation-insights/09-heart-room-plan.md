# 心事屋：明确独立交流、资料复用与页面实施计划

GitHub 工单：[#19](https://github.com/StarryJia/whomi/issues/19)；2026-11-15 已发布。

规划编号：H00。后续独立规划工单，不包含功能编码，不阻塞首期对话洞察。

## 目标与现状

设计不依附某段原始聊天的独立交流：用户进入心事屋表达困惑，模型可在用户允许的资料范围内理解背景，给出有依据的启发。资料复用的具体方式、范围和默认设置尚未确认。

现有模型对话围绕来源会话编号 `conversationId` 组织，不能直接视作心事屋后台。优先评估复用聊天呈现、已有模型选择、流式回答、停止与恢复能力；独立聊天存储和资料检索需先完成选型。

## 需求与资料边界

以下均为待讨论的虚构场景，用于定义结果，不代表已批准功能：

| 场景 | 要明确的行为与完成标准 |
|---|---|
| 用户未打开原始会话，直接说最近和朋友交流很累 | 进入独立交流，不要求选择某个原始会话，也不伪造来源会话编号。明确保存与再次打开的行为。 |
| 用户没有导入聊天，或尚未建立检索索引 | 确认是否仍可普通交流，以及如何呈现缺少背景资料的状态。 |
| 用户只允许使用小林的报告来理解背景 | 明确允许范围与来源展示；不能默认读取其他聊天，也不能将报告解释当成已证实事实。 |
| 回答途中停止、发生错误或来源被删除 | 明确哪些内容已经保存、怎样重试、旧引用如何失效，避免恢复时重复回答或引用失效材料。 |

- [ ] 确认新交流、历史保存、停止和重试的流程，明确无资料、未建索引与关闭资料复用时的体验。
- [ ] 确定允许复用的原始会话、报告和用户补充，用户怎样修改范围；不默认把所有心事写入共享资料库。
- [ ] 明确来源引用、旧认识被修正、资料撤销及独立聊天删除的处理，写出可观察的验收结果。
- [ ] 将已确认范围与未定事项写入独立规格，不用历史页面名称代替新的业务定义。

## 现成方案与最小验证

- [ ] 按可直接使用的完整产品、少量改造产品、可复用组件顺序比较最相关的至多三个候选；不足三个说明原因。
- [ ] 提供官方仓库、文档及核查版本，比较许可证、维护情况、部署和升级负担、隐私、费用及迁移成本。每个候选至少用上表一个场景说明能直接做什么、需要改造什么；区分官方支持声明与实际验证结果。
- [ ] 核查现有聊天组件与模型运行器能否脱离来源会话复用，给出采用、复用、必须自行实现的明确清单和推荐；不凭界面相似判断兼容。
- [ ] 与 Q00 共用一份资料检索方案。检索增强生成指先检索允许使用的材料，再交给模型回答；需要确定来源、索引建立与更新、删除失效、模型及本地或云端运行方式，不预设新增后台服务。
- [ ] 对会改变选择的兼容疑点提出最小验证，列通过标准、数据与模型、投入上限和停止条件，获得用户同意后执行。本工单发布不授权收费试验。

## 页面设计与后续拆分

- [ ] 需求与选型确认后，使用 **design-shotgun** 为需要新增或改版的入口、聊天与来源呈现出图。每次讨论一页，用户确认后附入对应工单，再进行下一页。
- [ ] 明确新交流、历史、无资料、停止、失败重试与来源失效等经确认场景的显示和恢复方式；常规窄窗和同布局简单状态复用已选设计验收，不机械要求独立图片。
- [ ] 使用 writing-plans 形成实施版计划，明确独立聊天数据契约、复用接口、文件职责、依赖及必要测试；方案确认后再拆功能开发子工单。

## 必用界面技能与证据

界面设计和后续实施必须写入以下三项，证据按[界面技能约定](../../../designs/conversation-insights/ui-skill-workflow.md)保存：

- **impeccable**：按既有系统与选定图设计独立交流页面，保留设计依据、选图与状态范围。
- **ui-ux-pro-max**：核查经确认的输入、停止、重试、资料提示、键盘焦点、对比度和桌面窄窗，记录适用于 Electron/React 的建议及处理结果。
- **design-review**：页面实现后对真实运行页面截图审查，修复后复查，交付前后截图、审查记录及未验证项；本规划阶段不记为已通过运行审查。

示例：用户发送困惑后请求失败，应按确认规则保留输入或已保存内容，提供可理解的重试方式；在真实页面验证全过程，不能只审查空聊天页。

## 交付与验收

- [ ] 独立规格明确交流流程、资料权限和无资料行为，未确认内容没有写成既定能力。
- [ ] 选型有证据与成本结论，明确既有聊天模块如何复用及必须新增部分，与 Q00 的共享检索约定一致。
- [ ] 需要新增或改版的页面附用户选定图和状态说明，三项必用技能进入后续实施验收。
- [ ] 实施版计划包含保存、停止、重试、来源失效等可执行场景；本规划完成不代表功能已开发，也不承诺未经确认的交付日期。
