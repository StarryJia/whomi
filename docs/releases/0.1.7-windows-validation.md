## 一次真实 ChatGPT 验收

在本轮的独立桌面构建中，用户在系统浏览器授权 Whomi 使用套餐，再在隔离的虚构空会话中亲自发送一次「只回复：收到」。Whomi 同步到当前账号的模型，并收到 GPT-6.1-Sol 的回答「收到」。截图只保留该回合和模型名。此临时验收档案与正式安装的 Whomi 资料独立。[真实问答截图](../../release/provider-account-validation/live-codex/one-turn.png) · [单回合记录](../../release/provider-account-validation/live-codex/result.json)

## 验证范围

- 新任务使用第三版文稿规则。已有成稿照原样可读，第一、二版暂停任务使用原来的整理指令。旧稿缺少新规则所需的事件计数，仍可阅读，但不投票。
- 使用真实的本地数据库、浏览器回调和模拟签名凭据，将套餐任务暂停在 8/24 后关闭。重启只续期一次，只请求第 9 至 24 条，模型版本保持。换账号会阻止沿用原账号的断点，换回原账号后可继续。
- Grok CLI 和 GitHub Copilot 均使用各自的 Whomi 应用身份。模拟覆盖设备码、等待、取消、模型获取、退出与缺少客户端标识时的提示。真实接入分别依赖获准使用的 `WHOMI_GROK_CLIENT_ID` 和 `WHOMI_COPILOT_CLIENT_ID`。本轮两家均未登录真实账户。
- 自定义服务商的四种文本协议由本机模拟端点验证。跨分片归并依赖能识别共同事件；测试材料中有明确关联，人格小样不衡量自由文本上的预测准确率。
