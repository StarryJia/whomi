# Whomi 0.1.10 · Windows 安装包验收

2026-11-02。在 64 位 Windows 上构建并核对了 `Whomi Setup 0.1.10.exe`。本地交付目录是 `release/0.1.10/`，安装包大小为 178,454,576 字节，未签名。SHA-256 文件校验值：

```text
2F301AE67F3AD995FAB4E8D9D06F4766A8F4072E8C4E4A960C5F04DABBFACA13
```

从安装程序提取应用后，逐一比对了其中 343 个文件，均与桌面构建相同。提取出的程序显示版本 0.1.10。升级验证先用 0.1.9 在独立资料目录导入 8 条虚构消息并选定本人，再用新程序打开同一目录：会话编号、8 条原文和本人选择均保留。未在日常使用的资料目录运行安装或卸载向导。
