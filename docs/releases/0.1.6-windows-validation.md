# Whomi 0.1.6 本地桌面验收

本轮在现有本地 `main` 上继续开发，起点为 `07fe5a8`。测试使用隔离的临时资料库、虚构中文聊天和本机模拟模型。桌面流程通过正式应用入口操作，右键、拖放、窗口缩放和重启均由 Playwright 驱动 Electron 完成。

| 场景 | 验收操作与结果 |
| --- | --- |
| 回原文核对引用 | 在 24 条虚构的搬家聊天中选 19 条，另加分页填充消息。发送后跳到首条，再翻页、返回、重启并重开引用。19 条有高亮，穿插的 5 条仍用原样式，定位失败可重试。[宽窗原文](../../release/handoff-validation/references/02-wide-referenced-and-skipped.png) · [窄窗原文](../../release/handoff-validation/references/05-narrow-referenced-and-skipped.png) |
| 整理两类列表 | 阅读甲时右键乙，可在置顶组或普通组内拖序。宽窄桌面均验证取消、失败重试与重启后的顺序。删除一条人工智能对话只影响该条问答，删除原始会话另行确认并清理关联成稿。[历史菜单](../../release/handoff-validation/lists/1280-history-menu.png) · [删除确认](../../release/handoff-validation/lists/440-original-delete.png) |
| 总览、回答与分栏 | 空库进入导入，已有聊天可从总览打开。原文、主导航、服务商列表分别拖宽并重启读回，双击各自的分隔线恢复默认值。回答状态位于本次回答图标下，首段文字出现后收起。[原文与对话](../../release/handoff-validation/overview-panes-status/05-two-panes-resized.png) · [服务商分栏](../../release/handoff-validation/overview-panes-status/06-providers-resized.png) · [360 像素回答状态](../../release/handoff-validation/overview-panes-status/08-waiting-360.png) |
| 生成、暂停与续跑 | 点击「整理成记忆」后取消，库内任务数仍为零。确认生成后在 8/24 暂停，重启只重新请求第 9 条及以后。模拟无效终稿，重试后原任务完成。主动「重新生成」产生第二份独立文稿。[暂停断点](../../artifacts/memory-library/05-restored-narrow.png) · [请求与任务记录](../../artifacts/memory-library/checkpoint.json) |
| 阅读与回到仓库 | 点击「查看记忆」直接打开当前任务，关闭后焦点回到仓库对应行。两份同源文稿可分别打开。每份新稿只有一次娱乐声明，三个标题顺序固定。[宽窗文稿](../../artifacts/memory-library/07-report-wide.png) · [窄窗文稿](../../artifacts/memory-library/08-report-narrow.png) · [同源的两份文稿](../../artifacts/memory-library/09-library-two.png) |
| 本人和关系贡献 | 小样中只保留有本人依据的安排偏好，其余维度留白。总览按维度列出各段关系的方向，可以打开来源成稿。更正本人后撤回失效方向，历史文稿仍可读。重生成暂停或失败保留此前完整结果。[总览](../../artifacts/memory-library/10-overview.png) · [计分小样与结果](../research/whomi-personality-small-sample.md) |

仓库沿用最新任务在前的顺序，用任务编号区分同源成稿。生成时复用前面分片的事件名称与已保存的进展，合并同一事件标识及明确的别名。测试覆盖了第一批商定搬家时间、第三批约同一趟货车时只产生一段记忆。两个片段没有共同标识或重叠证据、模型也未识别出关联时，仍可能重复叙述。
