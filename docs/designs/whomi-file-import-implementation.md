## 已完成的前端行为

| 范围 | 实现与可观察的例子 |
|---|---|
| 导入入口 | 移除独立数据导入菜单，将会话资料库改为会话；点击标题旁加号打开主区中央接收框，不改变抽屉状态，不建立空会话。主区没有额外的文件导入标题 |
| 文件选择 | 点击或拖入一个文件，只保留其名称；例如选择 example-file.txt，显示名称与已选择 · 尚未导入，可重新选择。取消选择不丢弃原名称；离开该页面后不保存选择 |
| 拖放边界 | 拖入文件时显示浅橙背景、加深边框和松开提示；移出恢复。一次拖入多个文件或文件夹提示重新选择，保留先前选择；在区域外放下文件不会让浏览器打开文件替换应用 |
| 独立抽屉 | 会话开关为右箭头／向下箭头，纵向收展与旋转 200 毫秒、透明度 160 毫秒；可反向操作，减少动态效果时直接切换。整个侧栏的既有 320 毫秒过渡保持不变 |
| 四种侧栏组合 | 宽侧栏且抽屉展开显示首字头像与名称；窄侧栏且抽屉展开只显示头像，悬停或聚焦可读全名。抽屉收起时隐藏全部会话项并移出键盘访问顺序；展开侧栏后管理和加号仍可用或显示不可用状态 |
| 阅读关系 | 选择一段前端传入的会话后显示姓名、首字头像和纯文本消息；明确标记本人时使用右侧浅暖色气泡，否则左侧显示。仅显示传入的时间，保留换行，不解释原文中的网页标记，不加载远程图片；没有消息输入或发送入口 |
| 保持正文 | 收起会话抽屉不卸载正文、不改变当前会话或滚动位置；切换会话才重新定位。例：阅读到 553 像素后关闭抽屉，实测仍为 553 像素 |
| 管理与设置 | 会话旁横向省略号为不可执行占位，提示管理会话 · 未开放；没有菜单、信息面板或删除逻辑。设置固定在底部，不随列表滚动 |
| 窄屏与焦点 | 640 像素及以下沿用窄栏和覆盖面板；选加号或会话后关闭覆盖面板，焦点进入文件选择按钮或会话标题。重复打开当前页面也恢复焦点；展开态品牌返回 Hello 仍保持侧栏展开 |

抽屉初次打开／刷新时收起且不记忆，是本轮已说明的实现选择，并非新增用户确认。长标题在列表单行省略，阅读标题换行并限制标题区高度；完整名称保留于可读标签。选中项同时提供浅橙背景、左侧细线与选中语义。大量数据下的表现仍需未来验证。

## 正式页面与虚构示例

正式入口 `/` 不传入任何会话，展开列表直接留空，宽侧栏与窄侧栏均不显示暂无会话文字、短横线或可聚焦占位；选择文件也不会改变它。`App` 的可选 `conversations` 参数只是前端组件输入，不代表接入数据库或导入服务。

2026-10-27 细节修订：按用户反馈移除 Hello 悬停与聚焦时的下划线，保留颜色反馈与键盘焦点轮廓。例如鼠标经过 Hello 时文字变为强调色，下面不再出现短横线；无会话时展开抽屉也不出现额外元素。

运行 `npm run dev` 后，访问 `/preview.html`，展开会话列表并选择项目讨论 · 示例，可查看只读气泡、长文本与空记录。此入口明确显示虚构示例 · 仅供前端预览，数据位于 `src/dev/preview.tsx`，并受开发环境条件约束；生产构建只处理 `index.html`，不包含预览入口或示例记录。

启动、刷新仍先显示 Hello；原始品牌资产和启动动画代码未在本轮修改。既有个人总览只有空状态，本轮没有扩展统计内容。

## 未实现与待确认

- 文件格式、来源、大小、真实导入数量限制和解析方式尚未冻结。当前单文件选择不能作为支持某种扩展名的证据。
- 没有读取文件正文、解析、上传、本地保存、身份确认、统计、模型调用或真实会话生成；不提供模拟进度、格式失败、解析失败或成功反馈。
- 成功后自动跳转还是由用户主动打开会话仍待确认；置顶、重命名、信息查看、删除影响范围与恢复方式仍待后续实现前明确。
- 没有目录扫描、接口导入、人工智能辅助导入、搜索、筛选或完整会话管理系统。

例如，用户现在选择一个损坏的聊天文件，页面只能显示名称，不能判断其解析结果；未来接入解析器后才能据真实错误提供重新导出的操作指引。
