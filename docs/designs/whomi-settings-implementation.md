## 已实现行为

以下操作示例均使用虚构数据，说明正式入口的可观察行为。

| 任务 | 正式行为与验收场景 |
|---|---|
| 返回正在阅读的会话 | 设置独立呈现，保留会话组件与草稿。例如输入草稿后进入设置、修改配置再返回，草稿和原阅读位置保留，模型列表刷新。 |
| 配置服务商 | 初始为空；支持自定义云端或本地 OpenAI Chat Completions 兼容地址、密钥及本地图片。显式保存；离开未保存表单可保存、放弃或继续编辑。已保存密钥只显示存在状态，替换或清除需再次保存。例如填写本地地址后重启，地址仍在而密钥输入框为空。 |
| 添加模型 | 同步只添加勾选项，手动添加始终可用；同名模型按服务商区分。不猜测未知容量，用户按服务商资料填写上下文和最大输出长度。例如同步返回两个标识，只选一个后仅该模型进入列表；部分添加失败可只重试剩余项。 |
| 检测与启停 | 检测发送固定简短内容，不发送聊天；不强制检测才能选择。修改连接参数使旧检测结果失效。运行任务须先停止，禁用或移除后不静默换模型，历史报告和对话保留。例如检测失败后修正地址可重试；已停用的当前模型不再允许发起新请求。 |
| 分别记住模型 | 分析和对话各自保存选择，切换会话继续沿用；保存失败保留原选择并在对应选择框附近显示错误。例如对话选择模型甲、分析选择模型乙，重启后两个选择仍不同。 |
| 处理发送材料 | 新用户默认开启清洗、合并、匿名化和脱敏，去噪默认关闭。连续发言窗口为 180 秒，可设为 1～600 之间的整数。已有用户保存的开关和秒数会保留。例如以前保存了关闭合并、60 秒，升级后仍可按这组设置使用。 |
| 脱敏规则 | 新用户默认选中 11 项中的 9 项，网络地址和网址可另行勾选。可分别选择接口密钥、授权令牌和普通密码。例如开启普通密码规则时，虚构的 `password="Blue Bird 42!"` 会发为 `password="[密码]"`，单独一条未标记的密码可能原样发送。关闭脱敏会保留勾选，恢复默认规则只重置勾选项。 |
| 保存目录 | 点击「当前保存目录」下的路径，在资源管理器打开该文件夹。点击「选择保存目录」，选择窗口从同一目录开始。选择另一个空目录并确认迁移后，应用复制并校验数据库及其事务文件、模型运行目录和导入暂存，再切换保存位置。原目录保留，导入源文件不移动。例如迁移到新位置后，点击新路径可查看迁移结果，重启后再选择目录也从新位置开始。取消选择保留原路径。 |
| 迁移失败恢复 | 活动导入或模型任务阻止迁移；失败恢复原服务，可重试并重新检查目标身份；服务无法恢复时显示重启入口。目录不可用的启动失败提供恢复指引，不另建空库代替。例如移动盘未连接时，用户连接磁盘后重新打开即可使用原目录。 |
| 关于与诊断 | 读取真实应用版本和第三方声明，项目链接交由系统浏览器打开。调试默认关闭；仅输出版本、运行平台和经过筛选的错误代码，可复制；不包含正文或密钥。不展示未确定的项目许可占位。 |

## 打开错误日志

Windows 安装版把错误日志写入 `Whomi.exe` 同级的 `logs`。例如安装在 `C:\Apps\Whomi`、将会话保存在 `E:\ChatData` 时，「设置 → 数据存储 → 打开错误日志目录」打开 `C:\Apps\Whomi\logs`，首次使用也可打开。导入页的「查看错误日志」直达 `logs\import-errors` 中对应任务的文件。

安装目录不可写时，应用显示失败路径，提示检查目录写入权限和磁盘空间。恢复权限后再次操作，新日志写回安装目录。迁移会话数据后，新日志仍写在安装目录。已有导入任务仍可通过「查看错误日志」打开原任务的文件。

日志仅记录时间、环节、错误码和必要的任务编号或统计信息。例如洞察用尽输出预算时，可以按任务编号找到已读条数和输出上限。聊天正文和凭据保存在各自原有位置。[桌面验收脚本](../../tests/desktop/application-logs.spec.mjs)

## 处理与存储边界

- 清洗只识别明确的分享卡片结构；去噪只过滤空正文及明确的系统占位，保留否定、语气和表情。例如单字消息“不”和动画表情不会被当作噪声删除。
- 同一人连续发送的文字从每段第一条起算窗口。恰好 180 秒可并入，超过窗口、换人或时间未知时分段。每段保留所有原始消息编号，可逐条回查原时间和原文。例如 10:00、10:02、10:04 的三条引用分成两段，对话洞察仍逐条读取。
- 昵称匿名化仅作用于发送者字段。例如虚构成员 7 的昵称为「小陈」，发送者变为 `U7`，正文「小陈说明天一起见陈洁」保留称呼。密码等敏感值在每条原文的发送副本中先处理再合并。
- 当前问题、可信引用、历史问题与回答、相关画像均在发送前处理；任意用户文本不会因为包含 id 等字段名绕过脱敏。更改处理规则使旧对话运行上下文失效；已有分析批次不与新规则混用，需要重新发起分析。
- 脱敏是基于已识别格式的替换，不能承诺识别所有敏感信息；不自动重新运行已有分析，不改写原始聊天。
- 密钥由系统加密后持久化，不返回已保存明文。配置迁移仍用于当前设备与系统用户，不承诺密钥可跨设备直接解密。
- 只接受经过本机选择授权的安全空目录，拒绝非空目录、源目录包含关系、链接及硬链接风险；失败清理仅限本次创建的副本。原目录备份不会自动删除。
