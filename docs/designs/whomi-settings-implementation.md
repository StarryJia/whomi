## 已实现行为

以下操作示例均使用虚构数据，说明正式入口的可观察行为。

| 任务 | 正式行为与验收场景 |
|---|---|
| 返回正在阅读的会话 | 设置独立呈现，保留会话组件与草稿。例如输入草稿后进入设置、修改配置再返回，草稿和原阅读位置保留，模型列表刷新。 |
| 配置服务商 | 初始为空；支持自定义云端或本地 OpenAI Chat Completions 兼容地址、密钥及本地图片。显式保存；离开未保存表单可保存、放弃或继续编辑。已保存密钥只显示存在状态，替换或清除需再次保存。例如填写本地地址后重启，地址仍在而密钥输入框为空。 |
| 添加模型 | 同步只添加勾选项，手动添加始终可用；同名模型按服务商区分。不猜测未知容量，用户按服务商资料填写上下文和最大输出长度。例如同步返回两个标识，只选一个后仅该模型进入列表；部分添加失败可只重试剩余项。 |
| 检测与启停 | 检测发送固定简短内容，不发送聊天；不强制检测才能选择。修改连接参数使旧检测结果失效。运行任务须先停止，禁用或移除后不静默换模型，历史报告和对话保留。例如检测失败后修正地址可重试；已停用的当前模型不再允许发起新请求。 |
| 分别记住模型 | 分析和对话各自保存选择，切换会话继续沿用；保存失败保留原选择并在对应选择框附近显示错误。例如对话选择模型甲、分析选择模型乙，重启后两个选择仍不同。 |
| 处理发送材料 | 默认开启清洗、合并、匿名化和脱敏，去噪默认关闭；合并默认 60 秒，允许 1～600 整数秒、步长 1。开关自动保存，失败恢复原值并可重试。例如邮箱和手机号会在真实请求中替换，原消息正文和编号仍保存在本地供阅读和回查。 |
| 脱敏规则 | 默认选择除网络地址和网址以外的 8 项；关闭脱敏保留选择，恢复默认只恢复规则。已知前缀密钥、Bearer 授权令牌、邮箱、手机号、身份证号、座机号按已识别结构处理，金融号码增加校验；可另选网络地址和网址。例如关闭后重开，用户原有的勾选仍在，合并时间不变。 |
| 保存目录 | 显示当前目录，选择空目录后明确确认迁移。复制并校验数据库、相关日志、模型运行目录和导入暂存；校验成功才原子切换目录指针。原目录保留，导入源文件不移动。例如取消选择不改变路径；非空目标被拒绝；成功迁移后重启仍能继续已有模型对话。 |
| 迁移失败恢复 | 活动导入或模型任务阻止迁移；失败恢复原服务，可重试并重新检查目标身份；服务无法恢复时显示重启入口。目录不可用的启动失败提供恢复指引，不另建空库代替。例如移动盘未连接时，用户连接磁盘后重新打开即可使用原目录。 |
| 关于与诊断 | 读取真实应用版本和第三方声明，项目链接交由系统浏览器打开。调试默认关闭；仅输出版本、运行平台和经过筛选的错误代码，可复制；不包含正文或密钥。不展示未确定的项目许可占位。 |

## 处理与存储边界

- 清洗只识别明确的分享卡片结构；去噪只过滤空正文及明确的系统占位，保留否定、语气和表情。例如单字消息“不”和动画表情不会被当作噪声删除。
- 合并保留全部来源编号，未知时间不合并；昵称编号对应真实成员编号。单字昵称只在消息头编号化，正文不做可能破坏语义的全局单字替换。
- 当前问题、可信引用、历史问题与回答、相关画像均在发送前处理；任意用户文本不会因为包含 id 等字段名绕过脱敏。更改处理规则使旧对话运行上下文失效；已有分析批次不与新规则混用，需要重新发起分析。
- 脱敏是基于已识别格式的替换，不能承诺识别所有敏感信息；不自动重新运行已有分析，不改写原始聊天。
- 密钥由系统加密后持久化，不返回已保存明文。配置迁移仍用于当前设备与系统用户，不承诺密钥可跨设备直接解密。
- 只接受经过本机选择授权的安全空目录，拒绝非空目录、源目录包含关系、链接及硬链接风险；失败清理仅限本次创建的副本。原目录备份不会自动删除。
