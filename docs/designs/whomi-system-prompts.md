# 系统提示词

系统提示词是 Whomi 在模型回答或处理聊天材料前给它的工作指令。桌面版「设置 → 系统提示词」按已接入的模型调用提供四项。用户可先点名称旁的叹号了解影响范围，再点同一行的「编辑」查看或修改全文。以下操作场景均为示例。

## 四项设置分别在什么时候使用

| 设置名称 | 说明中的对应功能 | 使用时机与示例 |
|---|---|---|
| AI 对话 | AI 对话 | 每次在会话侧窗发送新问题时，指引回答语气、交流方式和理解经历的角度。例如保存「先回应用户提到的具体经历」后，同一对话里下一次发送问题就会带上这句话。 |
| 记忆取材 | 整理成记忆 | 逐批阅读聊天原文时，提取共同经历，保留本人的具体选择和原文依据。例如一次活动改期，取材可以保留谁提出改期、对方如何回应，以及对应消息。 |
| 记忆归并 | 整理成记忆 | 取材结果太长、无法直接交给成稿步骤时，合并重复经历并压缩材料。例如同一次活动散落在几批聊天里，归并可把准备和改期合成一段。材料能直接成稿时跳过此步，即使归并提示词很长也不阻断该任务。 |
| 记忆成稿 | 整理成记忆 | 生成《我们的记忆》时，撰写主要经历、相处印象和有依据的人格倾向解释。例如要求「按事情发生的顺序写」，会随成稿请求发送。缺少依据的维度仍保留「暂难判断」。 |

这三项记忆指令允许改变模型的关注点与写法。自定义文本随各阶段必需的输出字段和依据要求一并发送，返回结果仍经程序校验。例如写入一条要求模型忽略原文编号的指令，不能让虚构的编号成为取材依据。[可编辑正文与默认值](../../src/shared/system-prompts.ts) · [各阶段固定要求](../../electron/main/prompt-contracts.ts)

## 编辑、保存与离开

- **选择条目。** 四行用分隔线排在同一列，每行只呈现名称、说明叹号和「编辑」。说明浮层只显示「作用」与「对应功能」。例如想改写作风格，先看「记忆成稿」的说明即可辨认受影响的功能，无需打开其他三份正文。
- **编辑与恢复。** 右侧抽屉显示所选条目的完整正文，正文框获得初始键盘焦点。点击「恢复默认」只替换当前草稿，点击「保存」才写入桌面本地设置。每次保存一项，重启后仍可读取。空白或超过 20,000 个字符的正文无法保存。
- **取消与重试。** 未修改时取消直接回到列表。带着草稿关闭时可选「继续编辑」「放弃修改」或「保存并离开」。保存失败时保留文字并就近显示错误，解决写入问题后再点「保存」。例如点过「恢复默认」又放弃修改，再打开时仍是此前保存的自定义正文。
- **键盘与窄窗。** 聚焦叹号后按 Enter 可打开说明，按 Escape 关闭并回到叹号。从「编辑」进入后，关闭抽屉时焦点回到原按钮。界面沿用现有设置按钮、分隔线和焦点色。360 像素宽时说明保持在窗口内，抽屉占满宽度，顶部让出 36 像素桌面标题栏，底部保留保存操作。[设置组件](../../src/components/settings/system-prompts.tsx) · [布局样式](../../src/components/settings/system-prompts.css)

## 保存后影响哪些请求

对话在**发送本轮问题时**记录所用指令，记忆在**确认并启动任务时**记录所用指令。失败重试、暂停续跑和重启恢复均沿用当时的文本。例如先暂停记忆甲，再修改「记忆取材」，继续甲时仍按旧文本整理；重新点击「生成记忆」创建的记忆乙使用新文本。对话同样按轮生效，在旧轮失败后修改设置，重试仍使用旧指令。

升级前没有记录提示词副本的任务沿用所属版本的内置指令，旧对话仍可使用兼容的已存断点。后续轮次改用不同的对话指令时，会保留已完成的对话历史，并使用新指令构建请求。[任务和对话保存逻辑](../../electron/data/ai/repository.ts) · [桌面设置存储](../../electron/data/ai/system-prompts.ts)

## 固定指令、历史版本与本轮材料

| 来源 | 实际发送的内容与用途 |
|---|---|
| 第一版会话分析（`conversation-analysis-v1`） | 分批分析与汇总代码共用旧分析系统指令，要求审慎总结已确认本人的表现并附真实消息编号。汇总另发送固定的用户指令「将这些批次观察汇总为一份结果，保留原文编号和限制：」，其后附本次批次结果。 |
| 第二版记忆（`conversation-memory-v2`） | 自有三份固定指令。取材保留事件及原文依据，归并压缩同一次经历并保留偏好，成稿输出各维倾向、主要经历及关系印象。例如恢复第二版任务时，仍读取第二版的事件格式。[第二版指令](../../electron/data/ai/memory-notes.ts) |
| 第三版记忆（`conversation-memory-v3`） | 另有三份固定指令。取材记录本人的主动选择，归并要求每个输入事件恰好属于一组，成稿返回分组、主要经历及关系印象，程序据事件分组计票。[第三版指令](../../electron/data/ai/memory-scoring.ts) |
| 当前记忆（`conversation-memory-v4`） | 取材、归并和成稿采用任务创建时保存的设置，并分别遵守对应阶段的数据格式。成稿还为达到门槛的维度引用具体经历。例如仅互发地址的材料不足以作出倾向判断。 |
| 模型连接检测 | 固定发送系统指令 `Reply OK.` 和用户消息 `OK`。即使修改「AI 对话」，检测内容也相同。 |
| 当前对话上下文 | 系统指令后附当前会话的相关画像，选用技能时再附本轮技能内容。用户消息包含本次问题和所选引用；已有对话历史另行传入。例如引用一句聊天再提问，该引用只作为讨论材料，不会写回「AI 对话」设置。 |

个人总览的「Spark · 不一样的自己」和「问一问」目前均没有独立的模型生成调用，因此本页没有对应的可编辑指令。[版本映射](../../electron/data/ai/prompt-version.ts) · [实际请求组装](../../electron/main/ai-service.ts)
