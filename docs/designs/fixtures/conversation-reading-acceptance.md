# 会话阅读固定验收输入

本文件全部为合成示例，供 2026-10-31 阅读完善方案重放，不代表真实用户材料或模型计量。

问题：这段示例里，我怎样回应了朋友？

## 完整回答源文本

```markdown
你把关心落实成了可执行的安排，而不只是安慰。

### 这段记录里发生了什么
朋友担心准备不完；你先问最卡住的部分，再提出明晚九点一起看材料，并确认对方希望先听建议还是先倾诉。

### 可以观察到的行为
- 先确认对方需要什么，避免直接替对方做决定。
- 把模糊支持变成具体时间与行动。
- 保留拒绝与调整的空间。

这些只说明这段示例中的行为，不能据此判断稳定人格。如果想继续理解，可以回看你在其他压力场景中是否也这样回应。

| 原文线索 | 有限观察 |
| --- | --- |
| 明晚九点我听你讲 | 提供具体可执行的支持 |
| 想先听建议还是先说说 | 尊重对方当下需要 |
```

该回答与上一轮实际对照内容一致。表格包含表头和两行数据；验收不能把 Markdown 分隔行算成数据行。

## 变体

| 编号 | 输入或条件 | 预期用途 |
| --- | --- | --- |
| F01 | 上述完整回答 | 标题、列表、表格、复制完整性 |
| F02 | `你提供了具体时间，也给对方保留选择。` | 短回答和气泡贴合内容 |
| F03 | 先送 `### 可以观察`，再补齐标题；先送半行表格再补齐 | 流式未闭合结构与已输出文字稳定性 |
| F04 | 表格一个单元格放入长文本，另放连续长链接和独立代码块 | 换行、局部横向滚动与整页宽度 |
| F05 | 输出 100、总耗时 10000 毫秒、首次输出等待 9000 毫秒 | 模型生成每秒 100，端到端每秒 10 |
| F06 | F05 不提供首次输出时间；另测总耗时等于首次输出等待 | 不伪造模型生成速度 |
| F07 | 输入 1240、输出 286、缓存读取 240、未缓存 1000 | 缓存与输入展示不回归 |
| F08 | 服务返回临时失败；用户新写 `后续草稿：请再说明一个具体行为。` | 重试保留新草稿，无重复用户问题 |
| F09 | 模型甲显示为 `合成对话模型`；模型乙为 `合成推理模型 · 长上下文 · 2026年10月` | 切换、长名称与历史身份 |

F03 固定分片顺序如下，相邻片段之间不添加额外字符；表中的 `\n` 表示一个换行：

1. `### 可以观察`
2. `到的行为\n- 提供具体时间。\n\n| 原文线索 | 有限观察 |\n| --- | --- |\n| 明晚九点`
3. `我听你讲 | 提供具体可执行的支持 |\n`

F04 使用 F01，将第一行数据的第二个单元格改为下列句子连续重复八次：`这是一段用于检查换行的合成长文本，单元格应保持两列对应关系。` 在表格后追加一个普通段落链接，地址为 `https://example.invalid/` 后接连续 180 个小写字母 a；再追加一个纯文本代码块，其唯一一行为连续 180 个小写字母 b。这是确定性生成规则，不依赖访问链接。

F03、F04 的确切输入和顺序在实现时保存进测试材料，复评继续使用同一份，不临时换成更短或更简单的输入。F05～F07 是计量契约示例，不用于真实模型性能排行。
