## 2. 用户任务、信息顺序与本轮边界

沿用已确认原则：让复杂的功能看起来简单，让简单的操作感到愉悦，让整个页面既有设计感，又不需要用户思考如何使用。

页面 02 是完成导入任务的操作空间，页面 03 是阅读原始记录的空间。用户准备好聊天文件后，先找到选择或拖放入口，再知道正在处理什么、结果是什么、下一步如何操作；不是先看格式选项卡、统计卡片或教程。

本轮交付静态视觉、交互约定及其前端实现。当前选择器一次选择一个文件；真实导入的格式、数量、大小、解析、身份识别、保存位置、重复导入及恢复能力均未冻结。没有接口导入、目录扫描、人工智能辅助导入或消息发送功能。置顶、重命名和删除仍保留在页面 03 的产品计划中，不因阅读示例出现会话行就默认全部实现。

## 4. 页面 02 与页面 03 的关系

以下成功路径是建议，尚不代表跳转方案已经确认：

```text
会话旁加号 → 文件导入页 → 选择文件或拖入文件
                         ↓
                      处理状态
                    ↙          ↘
          失败原因＋重新选择    完成结果＋打开会话
                                      ↓ 用户主动点击
                                 原始聊天阅读
```

- 加号只进入导入页，不同时切换抽屉、不创建空会话。示例：抽屉收起时点击加号，右侧进入导入页，列表仍保持收起。
- 建议成功后先保留结果，由用户点击打开会话再展示正文。示例：未来真实导入产生一个项目讨论会话时，结果提供打开会话；点击后列表展开并定位该项，右侧才出现原文。多会话结果的呈现留待文件范围明确后设计，不先承诺批量导入。
- 点击已有会话切换阅读内容；没有选择时不自动打开私人正文。示例：进入程序仍从 Hello 开始，不因为曾读过项目讨论而恢复其聊天内容。
- 阅读区只提供记录展示，保留真实来源的姓名、消息和已有时间；无时间不补日期，无头像使用中性占位。本人身份未确定时不擅自标为我。示例图的我只是已知身份的虚构示例。
- 展开态品牌返回 Hello 并保持侧栏展开；收起态 Logo 的悬停、聚焦和点击规则，以及启动动画全部沿用现有实现。

## 5. 独立的侧栏与会话抽屉

以下四种组合来自用户本轮明确反馈，不将两个开关合并：

| 整个侧栏 | 会话抽屉 | 可见内容 |
|---|---|---|
| 展开 | 展开 | 会话标题、独立管理图标与加号、具体会话头像与名称 |
| 展开 | 收起 | 会话标题、独立管理图标与加号；无会话行、头像、名称或预览 |
| 收起 | 展开 | 会话开关与头像列；名称通过悬停或键盘聚焦提示，头像可选择会话 |
| 收起 | 收起 | 只显示会话开关；无会话头像或列表项 |

图标提案：收起为向右箭头，展开为向下箭头；展开态位于会话文字左侧，窄栏中保留同一开关。可读名称分别为展开会话列表、收起会话列表，不与顶部展开侧栏、收起侧栏混用。箭头本身不承担导入操作。窄栏导入入口暂建议先展开整个侧栏，再使用会话标题旁加号，不额外发明第二个一级入口。

动画提案：约 180–220 毫秒，箭头转向与列表纵向展开、淡入同步；收起反向播放，途中反向操作从当前位置继续，按钮始终可用。整个侧栏继续使用原有 320 毫秒过渡，不修改品牌开场。减少动态效果时直接切换；收起立即移出列表项的键盘访问顺序，不让隐藏头像仍可聚焦。示例：列表展开到一半再次点击开关，列表直接反向收起，不等待第一段动画结束。

用户已确认抽屉收起时主区保持不变。例：阅读项目讨论到中间位置时，收起再展开抽屉都不切换会话、不重置阅读位置、不返回 Hello。此前抽屉修订图的中间示例只绘制侧栏状态，主区空白属于省略内容，不能作为新行为依据。设置继续固定底部，不随列表展开、收起或滚动移动。本轮实现选择初次打开或刷新时抽屉收起、不记忆状态，不自动恢复私人名称；这是实现选择，不记为新增用户确认。

## 6. 状态、窄屏与键盘设计

下表包含前端已实现状态与未来真实处理状态：无会话、拖入反馈、已选文件、长名称和键盘导航已实现；处理中、格式不支持、解析失败及成功仍为计划。实际文件选择不会触发模拟完成；独立开发预览标明虚构示例，正式入口不传入示例会话。

| 状态 | 主要表现与操作 | 判断是否符合设计的例子 |
|---|---|---|
| 无会话、未选文件 | A 的中央导入框；选择文件与拖放提示；侧栏会话列表直接留空 | 用户点加号后能立即找到选择文件；无会话时宽栏和窄栏都不显示文字或横线占位 |
| 拖入区域 | 接收边界加深、浅橙反馈，提示松开以选择文件；离开恢复 | 文件移出接收区不启动处理；不能仅凭扩展名显示支持该格式 |
| 已选文件但尚未接入能力 | 当前只显示真实文件名与重新选择，不显示成功 | 选择任意文件不能产生会话、百分比或导入成功通知 |
| 处理中 | 保留文件名，显示真实阶段；没有可测进度时不用百分比 | 真实处理尚未结束时，不通过计时器跳到成功 |
| 格式不支持 | 与文件就近显示无法识别文件格式和重新选择 | 用户换文件后恢复选择流程；格式未确认前不列出支持清单 |
| 解析失败 | 文件名、可理解原因和重新选择；详细原因来自真实结果 | 文件不能完整读取时说明请重新导出后选择，不能笼统显示成功 |
| 成功 | 明确完成结果与打开会话入口；仅在真实保存成功后使用 | 结果中的会话可在列表找到并阅读；本轮只记录设计 |
| 长标题与文件名 | 列表单行截断，悬停与聚焦可读全名；正文标题自然换行 | 很长的名称不挤走加号、开关或底部设置 |
| 长列表 | 仅会话列表在可用高度内滚动，设置和会话开关可见 | 最后一项仍能通过键盘到达，不能被底部设置盖住 |
| 窄屏 | 沿用 80 像素窄栏与展开覆盖面板；A 导入框随可用宽度缩小 | 375 像素宽度下不横向溢出；按钮与文字改为纵向、内容可滚动 |
| 键盘 | 原生选择按钮；开关用 Enter 或空格；独立加号；明显焦点 | Tab 聚焦只提示操作，不选文件、不展开正文；列表收起时焦点回开关 |

图标周围沿用约 48 像素点击区域。窄栏头像有完整可读会话名，选中状态不只靠颜色。窄屏选择会话或加号后建议关闭覆盖面板并将焦点移到主区标题；展开态品牌返回 Hello 仍保持侧栏展开，不能被这一建议覆盖。

本人身份不明、部分成功、重复导入和文件数量限制，等真实格式与处理范围确定后再细化；本轮不将这些状态删除，也不提前伪造其可用界面。原始聊天内容未来应按文本展示，不能把聊天里的标记当成可执行页面，也不自动请求原文中的远程图片。
