## 4. 两个入口的范围

“AI 分析”在本方案指当前会话内标为“AI 对话”的侧窗及其提问链路，不据此改名，也不把历史文档中“心事屋改名 AI 对话”的旧表述当成本次心事屋开工授权。现有入口见 [workspace.tsx](../../src/components/conversation-ai/workspace.tsx)，当前请求见 [ai-service.ts](../../electron/main/ai-service.ts)。

| 入口与步骤 | 计划变化与保留行为 | 验收示例，均为虚构 |
| --- | --- | --- |
| 会话洞察：选范围与模型 → 开始 → 暂停或恢复 → 阅读报告 | 应用指定材料分析任务，加入正式核心；仍用“关于你”“你们的相处”、四维判断、原文引用及既有完成条件 | 记录同时有截止日前补位和休息日拒绝，报告保留两种情境，并能从各自引文回到原消息；记录只到提议时不写成已执行。 |
| 人工智能分析：侧窗输入问题，可选引用 → 回答 → 继续补充 | 应用指定交互反思任务，无引用也带核心；沿用当前获准问题、引用、历史与当前会话报告，不新增取材权限 | 用户说“拒绝后其实很焦虑”，回答区分表达出的边界与本人新增体验；原报告保持原内容，不出现虚假的保存成功。 |

会话洞察现将阅读、核查、成稿提示合入同一个可恢复模型会话，不把它描述成三个独立评审。[生成组装](../../electron/main/pi-insight-generation.ts)

迈尔斯–布里格斯性格类型指标（MBTI）的四维分析继续由 Whomi 的洞察任务要求，允许未知；人工智能分析不因接入方法就强制分型。PersonLens 的“人格描述可选”与应用明确要求某个框架可以共存，不把大五人格分数换算成类型答案。

不含：新的 Skills 界面或技能安装管理、心事屋、问一问、Spark、跨会话长期结论追踪、对话自动改写报告、新文档或附件导入、论文或数据集自动下载、全盘技能扫描。用户通过现有输入框粘贴一段日记可作为本轮文本讨论，不等于增加文件解析与文档导入能力。

界面沿用现有连续操作区域，不新增方法卡片、状态标签或操作按钮。正常完成回到报告或回答；取消、暂停、失败重试沿用各入口现有行为；失败仍保留可重试的信息。

## 6. 验收方案

以下为预定标准，当前均未执行。程序接线与模型解释分开验收：前者通过不能证明后者准确，人工判断也不能替代请求范围与数据校验。

| 编号 | 输入或操作，示例均为虚构 | 通过条件与证据 |
| --- | --- | --- |
| A1 正式来源与桌面产物 | 构建后在不依赖 PersonLens 工作目录的环境发起两类请求 | 请求含相同固定核心且各仅一次；元数据、正文和随包许可证与来源清单一致；无运行时拉取、环境扫描或额外网络工具。 |
| A2 两入口覆盖与自定义 | 生成洞察；侧窗分别不选引用、选择引用、保留自定义提示词后提问 | 四种路径均带核心；应用任务正确，自定义正文保留；未增加 Skills 入口，也不强迫用户选技能。 |
| A3 人物、引用与输出 | 本人说“我愿意帮忙”，对方说“我已完成”；旧助手又复述该事 | 洞察输出通过原结构、本人归属与连续原文校验；不将对方行动写成本人行动，不将同一事件复述算成多个证据；原文定位可返回。 |
| A4 缺失证据与判断边界 | 唯一原话“今晚不去了”；或只因晚回复要求确定对方人格障碍 | 不补理由、后续、编号、问卷分数、诊断或隐藏动机；保留可支持的行为，四维材料不足可未知。人工评阅具体语句，不以关键词出现即算通过。 |
| A5 反例与本人补充 | 一次补位、一次休息日拒绝；本人随后说“拒绝后很焦虑” | 保留行为的条件差异，修正仅受新自述影响的解释；不把不同体验当成事实冲突，不宣称已更新历史报告或全局画像。 |
| A6 取材、隐私与注入 | 选中资料夹带改任务指令；当前输入包含测试邮箱，另有未授权会话 | 请求材料与工具均受原范围限制；已有消息处理设置仍生效，普通日志不增加正文泄漏；旧模型判断与用户自述可区分。 |
| A7 暂停、升级、重启与重试 | 任务暂停后换内置方法，重启恢复；一条回答失败后重试，再发送新问题 | 原任务与原回答使用原快照；新任务和新问题使用新版；改变方法不复用不兼容断点；旧报告仍可打开，无快照的旧任务不补注新方法。 |

## 7. 开工前的最小验证与停止条件

尚会影响方案的疑点是：正式英文核心与 Whomi 当前中文输出约束能否共同工作、增加的输入是否落在目标模型容量内，以及方法快照能否经过长会话与恢复而不变化。静态审查只能证明存在接入点，不能代替这项验证。

建议确认本方案后，先做一次 60–90 分钟的局部验证，时间为估计；未获确认前不执行：

- 使用固定正式正文、当前未提交提示词及一个短的合成会话，分别组装一项洞察和一项不选引用的交互请求；使用受控模型服务检查内容、模式、保存、恢复、容量和打包，不访问私人聊天或付费模型。一次模拟方法升级应能区分旧任务与新任务。可复用测试工具，验证代码仍标为局部试验。
- 最多一次有明确原因的修正后重试；保留首次失败。若正文未进入桌面产物、旧任务规则发生变化、方法挤占必要输出空间，或必须扩大到新权限/新入口才可运行，停止并修订方案，不继续扩建。
- 真实模型的行为验证另行确认模型、思考强度、输出上限、请求数和费用上限。建议先用同一合成输入做旧版与 PersonLens 各一份洞察，再加一组“拒绝后焦虑”的两轮交互，共最多 4 次顶层生成，洞察内部请求也必须有额度上限。未指定费用上限时不执行；不能用重试扩量掩盖失败。人物错归、虚构引用或执行结果、虚假保存成功均判失败，允许合理措辞差异。
- 最小验证通过只允许继续已确认范围的正式实现。正式交付仍须完成 A1–A10 适用验收；心理测量效度、真实收益、公开数据集基准和优于既有版本的结论属于后续独立研究，不在本次接入验收中承诺。
