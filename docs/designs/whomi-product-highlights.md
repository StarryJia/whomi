# Whomi 产品特色与介绍文案

日期：2026-10-28。用途：保存本轮设计思想，以及后续 README 和发布介绍可采用的文案。以下涉及 Spark、解惑、人格分析和 AI 对话的能力均处于设计阶段，未实现；正式宣传时按已交付范围调整，不能删除状态说明后直接当作现有能力发布。

## 设计特色

| 特色 | 为什么值得做 | 虚构体验示例 |
|---|---|---|
| 看见被忽略的一面 | 自我认识可以从熟悉经历中获得新角度，不必停留在人格标签 | 用户觉得自己不善关心，却发现自己一直记得朋友担心的事情 |
| Spark 自然浮现 | 有值得说的发现才出现，不要求用户反复点击生成，也不制造每日内容负担 | 一次交流补足了过去缺失的背景，才呈现新的观察 |
| AI 也会向你请教 | 不确定变成一次尊重用户的交流，而不是自信地误读 | 系统拿不准一句话是不是气话，将它留给解惑，等待用户说明 |
| 回到当时的心境 | 发现始终连着真实对话，用户可以自己判断是否贴切 | 点开依据回到那条消息及前后文，再返回原问题继续回答 |
| 你参与它对你的理解 | 赞同、不赞同和评论都能帮助修正观察，用户不必接受一个固定版本的自己 | 用户补充这只适用于工作，后续观察应保留这个情境 |
| 克制也是体贴 | 每日最多三个有价值的问题，没有新问题就不刷新，未答题不会被自动换走 | 用户隔天回来，仍能接着回答昨天尚未想清楚的问题 |

这些是本产品的设计组合与体验取舍，不宣称行业首创或已得到用户效果验证。被看见不等于持续被夸奖；有价值的观察可以让人惊喜，也可以帮助理解困扰，表达始终具体、温和、可纠正。

## README 简版文案

> 以下介绍的是正在设计的体验，相关智能功能尚未上线。

### 从熟悉的经历里，看见不一样的自己

Whomi 希望陪你回看自己的对话，发现那些曾经被忽略的表达、选择与关心。有时，一段熟悉的聊天换个角度看，会让你意识到：原来自己还有这样的一面。

**Spark · 不一样的自己**，在有值得分享的发现时自然浮现。每条观察都连着具体经历，你可以回到原对话，找回当时的心境，再判断它是否贴切。

**解惑**，给 AI 一个向你请教的机会。拿不准的话，不急着替你解释；每天最多三个值得问的问题，没有新问题就不打扰。你尚未回答的问题会留在那里，等你愿意继续。

**理解可以一起修正。** 赞同、不赞同，或说说自己的看法，都能成为下一次理解的起点。Whomi 希望让你感到被看见，同时保留解释自己的权利。
