## 用户任务与范围

用户在旁人身边打开程序时，希望先看到品牌和问候，主动点击后再查看个人内容。本轮将个人仪表台更名为个人总览并移除侧栏入口。个人总览只接入真实空状态，不编造统计或分析结果。

隐私封面用于避免意外展示，不提供身份验证。启动或刷新从封面开始，不保存或恢复上次打开的总览；返回封面后总览内容从页面中移除，而非仅覆盖一层图片。

## 入口与状态

- 启动或刷新：启动动画 → Hello。减少动态效果时直接进入 Hello。
- Hello 是原生按钮，外观保持简单问候；支持鼠标、Tab、Enter 和空格，聚焦本身不展示总览。
- 主动点击 Hello：进入个人总览空状态并将焦点移到标题。空状态提供返回 Hello 的按钮。
- 展开态品牌返回 Hello，立即移除总览，不重播动画，不改变侧栏展开状态。窄屏仍保持既有导航面板行为；收起态 Logo 继续承接展开侧栏操作。
- 仅启动或刷新自动播放开场，页面不提供重播和跳过按钮。动画期间背景界面不可操作，焦点留在开场区域；按 Escape 可结束，正常完成后焦点回到 Hello。

## Direction contract

THESIS：先问候，再由用户主动揭开个人内容；用发现小表情的品牌故事表达发现自己。

OWN-WORLD：沿用原始橙色图形、深色表情、系统字体和浅冷灰画布。放大镜与小脸均从原图提取，不重新描摹；两层保持原图相同画布和位置，最终自然组成 Logo。

STORY：原图放大镜保持形状与朝向，以开头的固定速度移动约 1.18 圈，开场即出现不可辨认的小黑点；小脸先加速靠近，在约一半大小时完全静止 0.3 秒，再快速冲近至原尺寸。放大镜的圆周终点直接对应最终位置，两层在同一时刻停稳组成 Logo；短停后整体缩小进入左上角，中央显现 Hello。

FIRST VIEWPORT（当时的导航方案）：首页主区仅呈现问候，曾列出数据导入、会话资料库、分析和底部设置；个人总览不占菜单。导航已随导入与会话前端调整，当前代码与下一版设计见[页面设计](whomi-page-design-v0.1.md)，不以本段冻结后续导航。

FORM：在既有客户端布局内扩展一次启动叙事，不重新开展整页视觉方向选择。隐私封面为 Operate，开场为有界的品牌 Experience。

## 约 3.8 秒匀速搜索分镜

| 时间 | 画面 |
|---|---|
| 0–0.2 秒 | 原图放大镜图片显现，中心小脸已是 0.028 倍的可见黑点 |
| 0.2–1.45 秒 | 小脸加速靠近并在约一半大小时放缓 |
| 1.45–1.75 秒 | 小脸保持 0.5 倍完全静止；放大镜继续匀速 |
| 1.75–2.2 秒 | 小脸以原有快速冲近曲线到达 1 倍；放大镜匀速到达圆周终点，两层同时停止 |
| 2.2–2.8 秒 | 两张图片自然组成完整 Logo 并停稳，不切换第三张完整图片 |
| 2.8–3.8 秒 | 两层组成的标识整体缩小归位左上角；界面与 Hello 显现 |

素材处理：`scripts/extract-brand-layers.py` 使用 Pillow 与 NumPy 从原始 `whomi-symbol.png` 分离 `whomi-lens-layer.png` 和 `whomi-face-layer.png`，两者保留 1254 × 1254 画布及元素在原画布中的位置。白底转为透明，内部原色保留；原始文件不改。动画全程使用这两张图片，不以矢量轮廓重绘放大镜、不用样式裁切整图取脸，也不叠加第三张完整图片。

时序实现：放大镜在 0.2–2.2 秒以每圈 1.7 秒的固定角速度运动，半径始终为画布的 0.06 倍。角度从约 -513.53 度推进至 -90 度，累计约 1.18 圈；圆周轨迹整体下移一个半径，使顶点直接对应原图坐标，无需收缩半径或额外回中。小脸初始缩放为 0.028、透明度为 1；0.2–1.45 秒使用 `power2.inOut` 到 0.5 倍，1.45–1.75 秒保持 0.5 倍，期间没有缩放动画，1.75–2.2 秒使用 `power3.in` 到 1 倍。两条运动均在 2.2 秒结束，两段冲近的时长和曲线保留，第二段直接从静止的 0.5 倍放大至 1 倍。

## 实现方案比较

- [GSAP](https://gsap.com/docs/v3/)：当前采用；用户已指定。复用现有时间轴、快速位置更新与 React 清理能力，自行编排原图分层和落点。例如保持放大镜匀速、固定半径，单独控制小脸三段放大并在同一时刻停稳。保留现有 `gsap` 与 `@gsap/react` 两个运行依赖，本轮不新增运行依赖。
- [原生浏览器动画](https://developer.mozilla.org/en-US/docs/Web/API/Web_Animations_API)：首轮采用；无需依赖，但需自行维护分镜调度。例如两圈位移与小脸放大需要手工协调，当前项目已有 GSAP，因此不再替换运行方式。
- [Lottie-Web](https://github.com/airbnb/lottie-web)：可播放预制作矢量动画，需要额外制作、导出和维护品牌素材。例如先做好搜索分镜，再在页面接入播放与原始 Logo 动态归位；本轮未采用。

## 验收与边界

- 正常开场约 3.8 秒结束；任何阶段按 Escape 均可直接到 Hello。启动动画和 Hello 封面均没有重播、跳过按钮。
- 放大镜运动中保持固定半径和原开头速度；小脸从黑点加速放大，中段完全静止 0.3 秒，最后快速冲近。例如用户看见放大镜匀速经过，小脸仍在冲近时放大镜继续运动，到 2.2 秒两者同时停止并组成 Logo，没有先停下等待或尺寸回弹。
- 减少动态效果、动画初始化异常或页面尺寸变化时，结束动画并保留可用封面。
- 桌面与窄屏使用真实品牌图片元素测量落点；背景标签页不继续播放不可见叙事。
- 返回封面不重播；刷新不先显示个人总览；禁用业务入口保持不可用。
- 本轮是浏览器界面，不伪造真实加载进度。将来桌面运行层的就绪状态单独接入。

## 历史连续形变修订（4.2 秒）

2026-10-27：用户明确要求问号出现后持续变形，在搜寻小表情时逐渐成为放大镜；中心目标起初只是不可辨认的小黑点，随后由远到近放大为表情。用户授权自行调整时长，本轮继续在已确认的 main 修改现有开场，不扩大页面范围。

采用约 4.2 秒：0–0.45 秒出现小黑点和问号；0.45–2.1 秒问号探头搜寻并连续舒展成镜圈，同一个句点移到标识末端；1.1–2.8 秒黑点靠近并显露表情；2.8–3.25 秒完整标识短暂停留；3.25–4.2 秒缩回左上角，Hello 显现。例如用户在形变中段始终看到一条连续的橙色轮廓，先看不出黑点是什么，随后在镜圈中心辨认出表情，不出现问号淡出后另一个镜圈淡入的空档。

复用现有原生时间轴、表情裁切、最终原图和清理逻辑。形变使用同一条 SVG 路径的数值插值，不增加动画库；避免依赖兼容性较窄的 CSS d 属性。表情从约 2–4 像素连续放大，保留中心位置，不单独替换一个黑圆。跳过、Escape、减少动态效果与窗口变化的恢复要求继续适用。

技术依据：[SVG 路径属性](https://developer.mozilla.org/en-US/docs/Web/SVG/Reference/Attribute/d)、[CSS 路径属性及兼容性](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/d)。前述 37 项验证属于首轮版本。
