# Whomi 0.1.1 桌面与会话细节修订

2026-10-30。用户确认修复当前版本并生成 Windows 安装包；本轮保留既有界面风格，采用定向回归与启动检查，不进行完整后台回归或模型效果评估。

## 已实现的行为

| 场景 | 操作与结果 |
| --- | --- |
| 首次启动桌面程序 | 默认窗口 1200 × 800，尺寸不超过当前屏幕工作区；用户调整后退出，再次打开恢复位置、尺寸及最大化状态。配置损坏或屏幕移除时回到可见区域。 |
| 使用窗口控制 | 移除默认 File、Edit、View、Window 菜单，顶栏与页面共用底色。复用 Electron 的系统窗口按钮；顶栏可拖动。 |
| 查看程序图标 | 使用用户指定的 hairline-v3b 图形生成透明外背景衍生素材；保留图标内部浅色底板。原始品牌文件不覆盖。窗口、程序文件与安装包使用同组图标。 |
| 开场结束 | Hello 保留操作焦点，但不显示启动产生的边框；用户通过 Tab 导航时显示焦点提示，鼠标按下时收起。 |
| 分析当前会话 | 浮窗正常状态只显示 根据当前会话的全部聊天内容，生成一份分析报告。以及确认分析、取消。后台身份、消息快照与模型核对仍执行；准备完成后才能确认。空会话、错误与进行中状态仍分别展示。 |
| 选择模型或技能 | 两处共用浏览器原生可定制选择器样式，统一背景、圆角、悬停及选中状态。保留原生方向键、Enter、Escape 与表单取值能力，不增加选择器依赖。 |
| 在窄窗口阅读 | 574 像素视口下标题与操作按钮同行，减少上下间距；极窄视口才换行。选择提示保留在标题下方。 |

全部会话内容指当前打开会话在确认时核对的材料快照，不表示跨会话读取，也不受用户已选引用范围限制。示例预览中的人物与记录均为虚构。

## 素材与复用

- 用户提供原图：`assets/branding/whomi-app-icon-hairline-v3b.png`。
- 桌面资源：`build/icon.png` 与包含 16、24、32、48、64、128、256 像素图层的 `build/icon.ico`。转换脚本为 `scripts/prepare-app-icon.ps1`。
- 下拉菜单采用 Chromium 的 `appearance: base-select` 与 `::picker(select)`；旧浏览器保留原生菜单作为回退，实际发布目标为项目固定的 Electron 45.1.0。
- 复用 Electron 的标题栏覆盖与系统按钮，不实现独立最小化、最大化、关闭通信接口。
- 打包使用 `signExecutable: false`，保留图标与程序版本资源写入；安装包仍为未签名的本地验证包。

官方依据：[可定制选择器](https://developer.chrome.com/blog/a-customizable-select)、[标题栏覆盖](https://www.electronjs.org/docs/latest/tutorial/custom-title-bar)、[默认应用菜单](https://www.electronjs.org/docs/latest/api/menu#menusetapplicationmenumenu)。
