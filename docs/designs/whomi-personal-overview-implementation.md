## 已确认的界面与范围

| 事项 | 本轮范围与具体示例 |
|---|---|
| 入口与封面 | 已按后续用户修订增加分析上方的个人总览菜单、Hello 主区悬停透视与点击进入过渡；品牌返回 Hello，不重播开场。例：用户从侧栏直接找到总览，或点击封面空白处进入，详见[入口修订](whomi-overview-entry.md) |
| 总览布局 | 采用第二轮方案，上方人格、下方 Spark；移除人格右侧相关会话列，关联方式另定。例：用户向下阅读具体发现，不必在两列之间切换 |
| 人格状态 | 展示四组中文偏好与类型汇总，允许 `E?F?`，全部未知为 `????`。未知不显示 50／50；已知均衡单独表达，不强选字母。例：只有两组已知时，另外两组保持问号 |
| 解惑 | 独立侧栏菜单，总览内不放解惑；本轮只有入口和真实空状态。例：没有待澄清材料时不生成三道示例题 |
| Spark 内容 | 需展示背景、交流经过、用户具体行为、解释限定与综合观察，不能从一句话下结论。虚构示例：先展示朋友的担忧、用户追问及后续跟进，再讨论关心是否通过行动表达 |
| 原文往返 | 原文条目是情境摘要；进入完整会话定位起止消息范围，保留前后文。例：查看追问和跟进后返回总览，尚未提交的只对熟悉朋友这样评论仍在 |

本轮页面只渲染传入的数据，不计算人格、不调用模型，也不自动生成 Spark。荣格八维、日历、趋势、数字百分比与人格依据新关联方式均未加入。

## 组件与数据接口

总览使用独立组件，与应用导航、会话阅读及开发数据分开。共享类型位于 [types.ts](../../src/components/overview/types.ts)。本节描述前端约定，不把接口存在等同于真实数据服务已经接入。

| 接口 | 职责与示例 |
|---|---|
| `OverviewData` | 区分无材料、未分析、部分材料和就绪，接收四组偏好及发现。例：部分材料仍可展示有效观察，其他维度保留未知 |
| `PreferenceEstimate` | 区分未知与已知；已知可偏向任一端或均衡，偏好程度使用文字状态。例：已知均衡与材料不足在四组说明中分别可辨 |
| `SparkDiscovery`、`SparkScene` | 将综合观察与场景背景、交流经过、具体行为、限定及来源分开提供。例：朋友担忧的经过与用户的实际回应分别可读，避免只有一句标签 |
| `SourceReference` | 关联会话、起始消息和可选结束消息，并提供情境摘要。例：一段三条消息的交流可以整体标记，不截断成一句摘录 |
| `FeedbackSaver`、`FeedbackReceipt` | 使用异步保存接口；回执区分真实保存与开发模拟，并独立保留后续分析状态。例：模拟回执只显示预览结果，不显示真实已保存或已修正 |

来源缺失、结束消息缺失或范围逆序时不得定位错误消息；真实索引创建、存储和删除后的关联处理仍属业务依赖。前端能够检查传入范围，不代表已经验证真实导入格式或本人身份。

## 反馈与恢复

- 赞同与不赞同互斥，可取消、更改；用户可直接评论，不要求先投票。例：先赞同后改为不赞同，仅保留后一种选择。
- 提交过程通过异步接口呈现处理中、失败与回执；未接入保存服务时不产生假成功。例：正式数据未接入时，不把点击按钮写成已保存。
- 失败重试使用失败时的提交快照，当前草稿独立保留。例：提交只适用于工作失败后，用户追加生活中不同；重试原提交不丢追加文字，也不把它误标为已提交。
- 原文跳转再回总览保留当前草稿与反馈状态；品牌返回继续遵守隐私封面约定。例：用户写到一半回查聊天后，可以继续输入，不必重写。

真实反馈持久化、评论编辑和删除、发现更新与旧反馈的关系，以及反馈对后续分析的修正均未实现。即使未来返回真实保存回执，也只代表反馈保存，不代表画像已经修正。

## 开发预览与正式入口

开发服务的 `/preview.html` 仅用于显著标注的虚构材料与边界状态，不进入生产构建。预览覆盖无材料、未分析、部分未知、已知均衡、无发现、场景化 Spark、来源缺失、反馈失败和长文本等状态；具体入口名称与实测结果以本轮验证为准。

例：开发者选择反馈失败场景，提交评论后检查错误提示与重试；切换到均衡场景，检查其与未知的区别。预览反馈只有模拟回执，不保存到浏览器或业务服务，不用于证明模型推断质量。

正式入口未接入真实分析和会话数据，个人总览、解惑及会话列表保持真实空状态。选择文件仍只显示文件名，不解析、上传、存储或生成会话。

## 业务依赖与尚未实现

| 后续依赖 | 当前边界与判断方式 |
|---|---|
| 真实解析、本人身份、存储和稳定索引 | 当前只接收前端传入会话；未来导入后需能定位真实消息范围，来源删除时不能跳错记录 |
| 人格估计与 Spark 生成 | 当前无推断算法；后续需验证材料门槛、情境覆盖及单句误读，不能把虚构示例当成准确率证据 |
| 反馈持久化与后续修正 | 当前只定义异步接口与模拟回执；未来真实保存失败可恢复，处理完成后再呈现实际修正状态 |
| 完整解惑 | 出题、每日额度、跨日未答题、回答处理与草稿持久化未实现；未来无合适问题时仍不凑题 |
| 会话分析与 AI 对话 | 会话级分析入口、模型配置和允许材料范围继续依照主设计；本轮总览展示不自动启用这些业务 |
