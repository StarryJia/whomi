## 1. 修复背景与解决问题范围

针对界面与审查报告（F01 ～ F13）以及用户明确要求，重点解决以下六大领域：

1. **信息噪声与状态表达**：
   - **F01 个人总览空状态**：无材料时展示简洁空状态与“选择记录”入口；有记录未分析时展示轻量说明，彻底移除未分析时的空偏好与空 Spark 卡片占位。
   - **F02 导入候选提示**：移除导入选择中“未配置本人”等泛化解释；保持界面诚实简洁。
   - **F04 模型服务设置**：空服务商时展示全工作区单一主要添加入口，移除空列表外壳。
   - **F05 冗余常驻提示**：移除模型服务设置底部固定常驻提醒“选择模型时，请同时确认服务商名称”。
   - **F06 施工痕迹清理**：消息处理设置移除“正式范围与步长待确认”等草稿文本，精简说明为“每次增减 1 秒，最小 1 秒。”。
   - **F07 问一问状态联动**：卡牌未接入提交时不再提示“点击即可提交”；已提交回答后隐藏无法执行的发送提示；撤回后恢复提交能力。
   - **F08 会话分析确认与空报告**：未生成报告时不假跳转；累计用量无数据时不补零；分析报告不存在时诚实展示“还没有已生成的分析报告”。
   - **F09 第三方声明清理**：清理 `THIRD_PARTY_NOTICES.md` 中试验历史、修图过程与草稿说明，只保留务实法律声明。

2. **会话顶栏布局（F10）**：
   - 彻底解决 Windows 原生系统窗口按钮（高 36px、宽 140px）与业务操作按钮冲突问题。
   - 移除此前 `padding-right: 164px` 造成的整行避让空白空洞。
   - 正文顶部保留 36px 系统拖拽与控制安全区，会话头部操作按钮区域增加 `padding-top: calc(36px + 12px)`（窄屏 `calc(36px + 8px)`），操作按钮垂直沉降至系统按钮下方，水平靠右对齐（右边距 24px，窄屏 16px）。
   - 保留整窗可拖动与系统控件无障碍点击，业务按钮全部配置 `-webkit-app-region: no-drag`。

3. **会话管理（F11）**：
   - 会话阅读器右上角增加“更多操作”菜单按钮，提供：
     - **选择本人**：弹出模态对话框，读取该会话真实成员列表，直观标注当前本人或来源推测，支持一键设为本人或清除本人设置。修改后即时刷新正文气泡左右对齐。
     - **删除会话**：弹出模态对话框，明确展示影响范围（级联物理删除该会话及其全部聊天记录、成员、本人设置、对话记录、导入关联与分析报告），用户二次确认后执行后端 `deleteConversation` 物理级联删除，随后自动返回个人总览并刷新侧栏。
   - 用户确认：备注名能力本轮暂不实现。

4. **导入职责解耦（导入只负责导入）**：
   - 导入流程移除“本人身份”下拉框及会话配置，将本人设置后置到会话管理中。
   - 增量导入必须显式选择目标会话或创建新会话，禁止同名静默合并；未指定本人时不自行猜测。

5. **导入完成、继续导入与问题提示（F03、F12）**：
   - **F03 预览体验**：消息预览使用可读时间格式（如 `2023/11/15 00:26`），去除无关分页与固定解释。
   - **F12 导入流转**：
     - 导入完成页清晰展示真实保存结果（保存条数）、“打开会话”主要操作与“继续导入”次要操作。
     - 点击“继续导入”清理缓存并恢复到初始选择起点。
     - 点击侧栏加号时，已完成的任务恢复文件选择起点；仍在进行、失败或部分保存的任务保留恢复入口。例如，用户在确认保存前离开导入页，再点加号，仍可继续保存或取消该任务。
     - 异常提示具体化并去重，指出具体文件、具体原因与影响，同一问题只展示一次。

6. **消息气泡紧凑自适应与对齐（F13）**：
   - 气泡正文样式配置 `width: fit-content; max-width: 100%;`，短消息（如“是滴”）气泡紧凑贴合文本，长文本自然换行。
   - 本人消息靠右（`align-self: flex-end`），对方消息靠左（`align-self: flex-start`）。
   - 发送人姓名与时间戳置于正文外，引用使用独立的紧凑气泡，不撑宽短正文；阅读区隐藏消息类型和附件状态。例如，动画表情记录保留正文占位，不额外显示“消息类型：表情”或“附件·文件缺失”。

7. **安装向导支持自定义路径**：
   - NSIS 配置 `oneClick: false` 与 `allowToChangeInstallationDirectory: true`，提供目标文件夹文本框与浏览按钮，保留本地数据完整性。

## 4. 2026-10-30 本轮验收补正

本节记录在已有本地修复基础上的实际补正；上节 180 / 288 项测试为前一轮记录。本轮继续当前 main，保留已有改动；远端刷新与拉取成功，本地领先 origin/main 16 个提交、落后 0 个。未创建提交或进行外部操作。

### 4.1 已完成行为

| 场景 | 修复后行为与验收点 |
| --- | --- |
| 用户阅读一条动画表情记录 | 保留原始正文，不显示消息类型、附件名称或缺失状态；正文空格与换行不改写。 |
| 用户阅读短消息，例如虚构验收数据中的“是滴” | 正文上下内边距收为 8px，行高 1.6，消息间隔 16px；姓名和引用不撑宽正文。实际桌面断言单行气泡高度不超过 42px、宽度小于 100px。 |
| 用户点击引用，而原消息位于已卸载的分页 | 使用真实目标编号读取所在页，气泡显示真实发送者与摘录，目标获得焦点及短暂高亮；可返回引用位置，输入草稿保留。普通引用跳转不增加来源范围标签和常驻定位成功提示。 |
| 引用没有可靠目标，或定位失败 | 无可靠编号时保留静态摘录；定位失败时保留原消息页，并提供重试定位。已有来源范围进入会话后再跳引用，焦点优先落在引用目标，不被旧来源起点抢回。 |
| 用户在确认保存或正在保存时离开导入，再点侧栏加号 | 恢复原任务；失败及部分保存结果也保留处理入口。已完成任务才清除本地任务编号并回到文件选择。 |
| 导入数据有未知时间、发送者或类型 | 识别解析器实际的小写警告代码，并指出具体问题及记录位置。该信息位于导入问题处理中，不出现在会话正文下方。 |
| 用户删除一段后文引用前文的会话 | 事务先清除整组引用再删除消息与目标键；删除成功，其他会话和数据库关联约束保持完整。 |
| 删除时模型任务运行中、排队中或刚完成入库 | 短生命周期控制操作按顺序完成；终止目标会话任务并等待写入结束，再执行删除。其他会话已运行的模型任务继续；删除失败时目标任务保留为可继续的停止状态。删除等待期间，新控制请求排队，完成后重新校验。 |
| 总览状态为部分完成或已完成，但没有有效观察 | 只显示一句空状态，隐藏全未知偏好和空发现卡片；已有真实偏好、均衡结果及发现仍保留。 |
