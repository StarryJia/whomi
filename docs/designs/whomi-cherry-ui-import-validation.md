# Cherry 交互与自动导入验收

2026-10-31。本轮在用户确认的 `main` 工作，开始时已将原有 22 个提交推送至 `origin/main`，基线为 `ff04097`。本轮只使用合成聊天、临时数据库和本机受控模型服务。

## 已完成的变化

| 场景 | 现在的行为 | 验证 |
| --- | --- | --- |
| 配置并管理示例服务商 | 右键进入编辑、备注或删除；连接修改失焦保存，失败保留输入并可重试 | 设置单元回归和真实桌面流程 |
| 同步与编辑示例模型 | 在侧面板中搜索、添加或移除，编辑名称、分组和三组容量；未声明容量保持空值 | 目录失败重试、已添加状态、精确预设、关闭重开及持久化 |
| 两个服务商有同名模型 | 菜单按服务商分组，支持搜索和键盘选择；选择结果保存服务商对应的模型编号 | 前端适配器回归、模型菜单截图 |
| 发送问题后继续输入 | 原提问进入本轮，输入区腾空；后来输入的草稿不会被旧回答完成事件清空 | 发送、流式响应、失败重试及引用唯一呈现回归 |
| 查看生成统计 | 模型、服务商、时间、输入、输出、生成速度与端到端耗时按 Cherry 结构呈现；未知字段不补零 | 缓存计数、首个输出等待与重启持久化 |
| 再次导入同一会话 | 可靠身份优先，连续五条消息补充；唯一匹配追加，零个或多个匹配新建 | 身份冲突、同文件、跨文件重叠、歧义和读取错误回归 |
| 导入没有平台消息编号的记录 | 按每个来源的出现次数去重；两份文件分别出现两次、三次时保留三次 | 独立事务回归及大文件资源测试 |
| 导入、取消或部分保存 | 单入口直接解析保存；不填目标、账号别名或预览消息。取消返回起点，部分保存保留真实结果 | 真实文件拖入、取消、损坏来源、重选与重启 |
| 窄窗口设置本人 | 原生模态层覆盖侧栏，保存失败保留选项，Escape 关闭弹窗并回到入口 | 360px 窗口、125% 缩放、菜单边缘点击矩阵 |

“选择本人”原截图所示的 Windows 原生鼠标首项阻断没有稳定复现。已经复现并修复的是侧栏遮挡本人弹窗、Escape 被消息选择模式截获；Electron 内部点击矩阵通过。原生工具未能取得有效的指针几何信息，不能把这些结果说成原始症状已经完成原生鼠标验证。
