# Whomi 设置独立预览

这是 A 专注分栏的设计与交互演示，不接入正式客户端入口。在仓库根目录运行 `npm run dev`，再打开 `/docs/designs/previews/settings/index.html`。视觉修订与首轮比较见上级 `whomi-settings-concepts.html`。

三个分类共用 Whomi 既有字体、颜色变量和品牌资产。数据仅存在于当前页面内存；刷新或重置演示会恢复演示起点。切换分类、返回示意入口再进入不会主动保存配置。

- 模型服务：示例云服务与示例本地服务、搜索、字段编辑、图片选择、模拟检测、模型多选及增改移除；顶部演示选项可切换无服务商、无模型、长内容和失败。
- 消息处理：五项开关、从属秒数输入、十条分组规则、部分选中与恢复演示选择；没有消息转换、识别或脱敏程序。
- 关于whomi：原始品牌、包版本、一个了解你的程序介绍、真实仓库、已有第三方声明及调试模式演示。开启调试模式只展开预览环境和版本信息，不读取真实日志。

服务商图片只读取 PNG、JPEG、WebP 用于本次预览，不上传、不持久化。图片选择验证使用项目已有 Logo PNG 作为输入，不代表预置服务商素材。常规服务商清单等待用户提供；示例服务和协议选项不代表已确认支持范围。

正式开关初值、规则默认选择、合并参数、恢复默认范围与保存方式均待确认。预览中的 180 秒、每次增减 1 秒及邮箱与手机号初选仅用于演示。

类型检查：在仓库根目录运行 `node node_modules/typescript/bin/tsc -p docs/designs/previews/settings/tsconfig.json`。本目录的类型检查独立于正式源代码，不修改包脚本或正式构建入口。

实际检查和未验证事项见[设置设计文档](../../whomi-settings-design.md)第 11 节。
