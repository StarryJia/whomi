我们的记忆

那张贴反的路线图

读书市集开场前，你在入口贴路线图，小林搬来最后一摞书，才发现图上的箭头朝着出口。你们一起揭下重贴。散场后，他把改好的地图拍给你，说下次还可以接着用。你们的聊天就是从那张照片开始的。

只有十分钟的试讲

两周后，小林为周五的汇报发愁。你问他想先改稿，还是先找个人听一遍。他选了试讲，晚上九点打来电话。听到第二遍时，你才发现他把原来放在结尾的那个例子挪到了开头。隔天他告诉你，这回终于讲顺了。

可以改期的河边散步

月底，你提起最近工作收得晚，小林约你去河边走走。你想顺路看看旧书店，又担心周六临时加班。他说可以当天再定。聊天停在你发来的书店位置，散步的日子还空着。

我们的关系

最初你们找对方，手边总有一件具体的事：贴对地图，或者把那几分钟的汇报讲顺。到了最后，是小林先来问你有没有空出去走走。听上去，一起做事之外，你们也开始给闲聊和见面留一点位置。

我很喜欢试讲和散步之间那个小小的呼应。你先问小林需要怎样的帮助，他后来也给你的周六留了余地。两次都没有逼对方当场作决定。至于这样的默契会不会成为日常，这份聊天还没写到那里。
