## 暂缓与后续工作

- 荣格八维、日历、趋势热力图、每日人格分数只保留想法，不放占位界面。
- 解惑和 AI 对话的功能关系已确认，实施顺序与上线排期另定。
- 偏好计分和判断门槛、解惑跨日额度、索引与存储、原文权限、反馈处理与删除影响仍需明确。
- 下一步先用虚构材料演练有依据的发现、气话误读、部分认同，再确认视觉稿和实施范围；本轮仅文档同步。

维护时以用户最新明确决定为准，在主设计记录原因与边界，再同步摘要。历史记录只增加适用范围说明，不把旧测试数量、旧图稿或旧授权改写成当前能力。
