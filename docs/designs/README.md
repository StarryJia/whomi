## 暂缓与后续工作

- 荣格八维、日历、趋势热力图、每日人格分数只保留想法，不放占位界面。
- 解惑前端已实现并提供独立开发预览；正式入口保持真实空状态。问题生成、每日额度、持久化与模型处理，以及 AI 对话业务另行安排。
- AI 对话与旧版固定提示词已接入桌面 Pi 后台，独立开发预览使用虚构材料。新建记忆任务使用独立版本的事件归并与文稿模板，结果从记忆仓库打开。用户技能只作用于主动对话。
- 偏好计分和判断门槛、解惑跨日额度、索引与存储、原文权限、反馈处理与删除影响仍需明确。
- 总览第二轮视觉与前端范围已确认；开发预览展示显著标注的虚构材料。真实分析仍需验证气话误读、部分认同及情境限定，不能以预览代替模型效果验证。

维护时以用户最新明确决定为准，在主设计记录原因与边界，再同步摘要。历史记录只增加适用范围说明，不把旧测试数量、旧图稿或旧授权改写成当前能力。
